使い方: yomiyasu_diff.py [--stance 立場] [--doc-type 種類] [--reader 読者] [--json] [--fail-on meaning-risk]
                        [--words フォルダ | --no-words] [--material 資料 ...] 元の文 書き直した文
       yomiyasu_diff.py --endings ファイル [--stance 立場]
       yomiyasu_diff.py --version

元の文と書き直した文を比べ、変わった箇所をすべて出し、意味が変わる恐れと規則の見直し候補を挙げます。全文差分は意味が同じだという証明ではありません。意味が同じかどうかは判定しません。

引数:
  ファイル                  比べる2つのファイル（UTF-8）。元の文、書き直した文の順に渡します。どちらか1つに -
                        を渡すと標準入力を読みます。--endings のときは1つだけ渡します。

オプション:
  -h, --help            このヘルプを表示して終わります。
  --stance 立場           文書の立場。勧め（読み手に勧める）、決まり（手順）、説明（報告、体験）のどれか。文末の見直し候補の出し方が変
                        わります。
  --json                結果をJSON（形式2）で出します。日本語は \uXXXX の形で出します。
  --fail-on meaning-risk
                        意味が変わる恐れのうち、数値、否定、主語と目的語の入れ替え、文の種類（問いと平叙、文の種類を表す語）、引用の
                        書き方の変化、確度を強めた書き換え（かもしれない → 見込み、見込み → 予定、と思われる → 断定など）、
                        原文の状態の語（未定、未確認、調査中など）が消えた書き換え、原文にない書き手の約束・保証・再発防止の誓いを足
                        した書き換えが1件でもあれば、終了コード1で終わります。許可の言い方（してよい、してもよい、構わない）が消え
                        たか増えた書き換えも数えます。事実や仕様を述べる種類（--doc-type が pr、article、inc
                        ident、proposal、manual、formal、paper）では、「場合がある」「ことがある」を消
                        して言い切った書き換えと、断定に「必ず」「確実に」などを足した書き換えも数えます（ほかの種類と種類なしでは数
                        えません）。能力の言い方（できる、可能だ）が消えた書き換えは、どの種類でも数えません。コード・URL・引用ブ
                        ロックなど変えない箇所の変化は、意味が変わる恐れとして出しますが、この条件には数えません。否定対比の主張の逆
                        転と、元にない気持ちの語も数えません。確度を弱めた書き換え、数えない語だけの確度の変化、予定の言い切り（する
                        予定です → します）、かぎかっこの中の言葉の変化も数えません。推量の言い方が、同じ強さの別の慎重な言い方に
                        替わっただけの文（かもしれません → 恐れがあります、と思われます → 見込みです）も数えません。原文にない
                        因果のつながりを足した書き換えと、書き手の行為と読む言い方（いたします、今後・改めて、弊社などの主語）のない
                        「〜します」を足した書き換え（説明や手順の文かもしれないもの）も数えません。ただし、関連・相関を述べた原文の
                        文に因果の言い方（因果、原因、引き起こす
                        など）を足した書き換えと、選ぶ範囲が入れ替わった書き換え（または・どちらか →
                        両方・すべて、またはその逆）、同じ数に付いた概数や範囲を表す語（約、ほど、以上、未満 など）が消えたか増えた
                        書き換えは数えます。候補は確かめる場所で、意味が変わったという判定ではありません。条件に当たらなくても、意味
                        が同じだという証明にはなりません。何度でも、カンマ区切りでも指定できます。
  --doc-type 種類         文書の種類（値は yomiyasu_lint.py と同じ）。表示と JSON に残します。差分、意味が変わ
                        る恐れ、規則の見直し候補の見つけ方は、どの種類でも同じです。pr、article、incident、prop
                        osal、manual、formal、paper（事実や仕様を述べる種類）では、「場合がある」「ことがある」
                        を消した言い切りと、断定に「必ず」などを足した書き換えを --fail-on
                        に数えます（意味の検査で種類によって変わるのはこの2つだけです）。文体の硬化の検査は
                        incident、formal、paper のとき、勢いの検査は
                        pr、article、incident、manual、formal、paper
                        のとき、候補を参考として出します。promo と mail
                        以外の種類を指定すると、勢いの検査の絵文字の候補も参考として出し、promo、minutes、mail
                        以外では見出しの候補も参考として出します。promo
                        では、番号つき項目の行と太字だけの行も勢いの検査の見出しに数えます。mail
                        だけ敬語の度合いを検査します。値: pr（PR説明）、article（技術記事）、incident（障害報告
                        ）、proposal（提案書）、minutes（議事録）、manual（マニュアル）、slides（スライド
                        ）、essay（エッセイ・小説）、formal（公用文、規程、契約書、仕様書）、promo（紹介記事・宣伝文
                        ）、mail（メール・チャット）、paper（論文・研究レポート）、script（台詞・脚本）。
  --reader 読者           想定する読者の知識（値は yomiyasu_lint.py と同じ）。表示と JSON
                        に残すだけで、判定は変わりません。
  --words フォルダ          語の一覧（allow.txt と flag.txt。名前と正規表現を書く flag-patterns.txt
                        も置けます）のフォルダ（値は yomiyasu_lint.py
                        と同じ）。省くと、作業ディレクトリから上へたどった git の最上位（.git のあるフォルダ。git
                        の外では作業ディレクトリ）の .yomiyasu-words/ を探します。linked worktree
                        にこのフォルダがなければ、元の checkout の一覧を探します。diff では一覧の場所と語の数を表示と
                        JSON に書きます（差分と候補は変わりません）。
  --no-words            語の一覧を探さず、読みません（--words と一緒には使えません）。
  --material 資料         資料のファイル。何度でも指定できます。原文にない人や担当を足した文の検査で、資料にある人や担当は出しません。
                        ほかの検査と、意味が変わる恐れの数は変わりません。
  --endings             1つのファイルの文末の種類と、立場の混ざりだけを見ます（--json、--fail-
                        on、--words、--no-words、--material は使えません）。
  --version             バージョンを表示して終わります。

終了コード:
  0  比べ終わり、--fail-on の条件に当たらなかった（候補の有無によらない）。--endings の正常終了、-h と --version も0
  1  --fail-on=meaning-risk の条件に当たった（数値、否定、主語と目的語の入れ替え、文の種類・引用の書き方・確度・状態の語・約束・許可の言い方・選ぶ範囲・因果の恐れが1件以上）
  2  使い方か入力の誤り（ファイルを開けない、読まないファイル（作業フォルダの外、名前が点で始まる部分を含むパス）を渡した、UTF-8 として読めない、標準入力を読めない、使えない --stance、--fail-on、--doc-type、--reader の値、ファイルの数の誤り、語の一覧を読めない（--words のフォルダがない、UTF-8 でない、1万行を超える、flag.txt か flag-patterns.txt に使えない行がある。ファイルの中身の誤りは、ファイルの名前と行番号を出す）、--words と --no-words を一緒に指定した）
  3  予期しない内部の誤り（標準エラーにトレースバックを出す）か、出力先が閉じられて結果を最後まで書けなかった
