# treefiler

横に育つ木のファイラー。左から右へ木が育ち、開いたフォルダは列として右に並ぶ。カーソルまでの経路は画面の中ほどの
固定の線に乗り、上下に動くと列の方がスクロールする。ファイルを開くと中央にタイルが開き、本文中のパスから
別のファイルを開くと、タイルが手前に重なっていく。見た目は [treebeard](https://github.com/freakinfrick/treebeard)
(MIT OR Apache-2.0) を写している。

```sh
bin/treefiler [DIR]   # DIR (既定はカレントディレクトリ) を root にして開く
```

glogx からは `F` で同じ画面が開く。仕様とキーの一覧は [`docs/treefiler-spec.md`](../../docs/treefiler-spec.md)。

## キー (木)

| キー | 動作 |
|---|---|
| `j` `k` / `↓` `↑` / `Ctrl-N` `Ctrl-P` | 同じ階層の中で移動 (開いたフォルダへは潜らない) |
| `J` `K` | 同じ階層の中で 10 件 |
| `Ctrl-D` `Ctrl-U` / `f` `b` | 同じ階層の中で半ページ |
| `g` `G` | 兄弟の先頭 / 末尾 |
| `l` `→` `Ctrl-F` `Enter` | フォルダなら潜る、ファイルならタイルを開く |
| `h` `←` `Ctrl-B` | 親へ |
| `Space` `Tab` | フォルダの開閉 |
| `c` / `C` | このフォルダを畳む / 経路以外を全部畳む |
| `-` `Backspace` | root を 1 段上へ |
| `.` | dotfile の表示の切り替え (設定に保存する) |
| `,` | 設定の板 (`j` `k` で選び、`h` `l` `Enter` で変える、`r` で既定へ、`Esc` `,` で閉じる) |
| `/` | カーソルの列の中をあいまい検索 (打つたびに一致へ飛ぶ。`Tab` `↓` `↑` で一致を移る・`Enter` で留まる・`Esc` で戻る・空欄の `↑` で前回の検索) |
| `n` `N` | 前回の検索の次 / 前の一致 |
| `e` | 配下のフォルダを全部開く (400 フォルダ / 6000 件で止める。隠したフォルダと git が無視するフォルダには降りない。`Esc` で中断) |
| `?` | キーの一覧 (`?` 以外のキーで閉じる) |
| `o` | 外のアプリで開く (`open`) |
| `r` | 読み直す (開いていたフォルダは開いたまま) |
| `!` | 選んだフォルダで 1 行のコマンドを実行 (`$f` が選んだパス。`↑` `↓` で履歴。3 秒未満で終わったら出力を読めるようキーを待つ) |
| `s` | 選んだフォルダでシェルを開く (抜けると戻って読み直す) |
| `q` `Esc` `Ctrl-C` | 終了 |

## キー (タイル)

| キー | 動作 |
|---|---|
| `j` `k` / `Ctrl-D` `Ctrl-U` `Space` / `g` `G` | スクロール |
| `Tab` | 本文中のパスを選ぶモード (`Tab` `j` `k` で選び、`Enter` で手前に重ねて開く、`Esc` で戻る) |
| `J` `K` | 開いたまま同じフォルダの隣のファイルへ |
| `d` | git の diff と本体を切り替える (変更のあるファイルだけ。右下に `d diff` と出る) |
| `o` | 外のアプリで開く |
| `q` `Esc` `h` `←` `Enter` | 手前の 1 枚を閉じる |

入力欄 (`/` の検索・`!` のコマンド) には貼り付けられる (入力していないときの貼り付けは捨てる)。
git の印とブランチは、root と開いているフォルダが属する repo ごとに出す (root が repo の外で配下に repo が並ぶ場合も)。ブランチはカーソルの repo のもの。

Markdown は整形して、コードは言語ごとに色を付けて出す (外部コマンドは呼ばない。`tuikit/markdown` と `tuikit/highlight`)。
長い行は折り返す (設定の Wrap lines で切り替え)。
音声・画像・PDF・バイナリは開かず、toast で知らせる (画像は後で対応する。issue 688。PDF は写さない)。

## 設定

`,` の板で変えた値はその場で効き、`~/.config/glogx/treefiler.toml` の 1 行だけを書き換えて保存する (他の行とコメントは残す。
手で書いてもよい。形式は `key = value`)。読めない行は既定のまま使い、板の足元に何行目かを出す。
`TREEFILER_CONFIG_DIR` で置き場所を差し替えられる (テストはこれで本物を触らない)。

`Remember place` を on にすると、閉じたときの開いたフォルダとカーソルを起動したフォルダごとに `~/.config/glogx/treefiler-places`
へ覚え、次に同じフォルダから開いたときに戻す。
