# treefiler

横に育つ木のファイラー。左から右へ木が育ち、開いたフォルダは列として右に並ぶ。カーソルまでの経路は画面の中ほどの
固定の線に乗り、上下に動くと列の方がスクロールする。ファイルを開くと中央にタイルが開き、本文中のパスから
別のファイルを開くと、タイルが手前に重なっていく。見た目は [treebeard](https://github.com/freakinfrick/treebeard)
(MIT OR Apache-2.0) を写している。

```sh
bin/treefiler [DIR]   # DIR (既定はカレントディレクトリ) を root にして開く
tf [DIR]              # bin/tf は bin/treefiler の短い名前
```

tmux では `prefix + f` (`C-t f`) で、いま見ているペインの cwd を root にした popup が開く (`_tmux.conf`)。
glogx からは `F` で同じ画面が開く。仕様とキーの一覧は [`docs/treefiler-spec.md`](../../docs/treefiler-spec.md)。

## キー (木)

| キー | 動作 |
|---|---|
| `j` `k` / `↓` `↑` / `Ctrl-N` `Ctrl-P` | 同じ階層の中で移動 (開いたフォルダへは潜らない) |
| `J` `K` | 同じ階層の中で 10 件 |
| `Ctrl-D` `Ctrl-U` / `f` `b` | 同じ階層の中で半ページ |
| `g` `G` | 兄弟の先頭 / 末尾 |
| `l` `→` `Ctrl-F` `Enter` | フォルダなら潜る、ファイルならタイルを開く |
| `h` `←` `Ctrl-B` | 親へ (root なら root を 1 段上へ。カーソルは動かない) |
| `Space` `Tab` | フォルダの開閉 |
| `c` / `C` | このフォルダを畳む / 経路以外を全部畳む |
| `>` | 配下のフォルダを全部開く (ファイルの上では親が対象。400 フォルダ / 6000 件で止める。隠したフォルダと git が無視するフォルダには降りない。`Esc` で中断。見える項目が 100 件以上なら確認の板を出す) |
| `<` | このフォルダと配下を全部畳む (ファイルの上では親が対象。`c` と違って配下の開閉を覚えない) |
| `-` `Backspace` `Ctrl-H` | root を 1 段上へ |
| `.` `I` | dotfile (隠しファイル・フォルダ) の表示の切り替え (設定に保存する) |
| `,` | 設定の板 (`j` `k` で選び、`h` `l` `Enter` で変える、`r` で既定へ、`Esc` `,` `q` で閉じる) |
| `/` | カーソルの列の中をあいまい検索 (打つたびに一致へ飛ぶ。`Tab` `↓` `↑` で一致を移る・`Enter` で留まる・`Esc` で戻る・空欄の `↑` で前回の検索) |
| `n` `N` | 前回の検索の次 / 前の一致 |
| `e` | エディタで開く (ファイルもフォルダも。`$VISUAL` → `$EDITOR` → `nvim`。閉じると戻って読み直す) |
| `?` | キーの一覧 (`?` 以外のキーで閉じる) |
| `o` | 外のアプリで開く (`open`) |
| `O` | Finder で選んだ状態で見せる (`open -R`) |
| `y` `Y` | パスをコピー (`y` = 絶対パス・`Y` = root からの相対パス) |
| `:` | 入力したパスへカーソルを飛ばす (絶対パス・`~/…`・root からの相対パス。貼り付けも効く。root の外なら共通の祖先まで root を上げる。無いパスでは動かない) |
| `a` | 新規作成 (カーソルのフォルダ、ファイルならその親に、足元の入力欄で名前を入れて作る。末尾を `/` にするとフォルダ。既にある名前・`/` や `..` を含む名前は断る) |
| `m` | 名前の変更 (今の名前を入れた入力欄で直して `Enter`。同じフォルダの中だけで、既にある名前へは変えない。root は変えない) |
| `d` | ゴミ箱へ移す (確認の板で `y` `Enter` だけが実行。Finder と同じ `~/.Trash` へ移し、同じ名前があれば `name 2` のように番号を足す。消さない。別のボリュームの項目は断る。Finder の「戻す」は効かない) |
| `S` | 並びを巡回 (名前順 → 更新の新しい順 → 大きい順。設定の板の Sort by と同じ。逆順は板の Reverse) |
| `r` | 読み直す (開いていたフォルダは開いたまま) |
| `!` | 選んだフォルダで 1 行のコマンドを実行 (`$f` が選んだパス。`↑` `↓` で履歴 (閉じても `~/.config/treefiler/treefiler-history` に残る。先頭を空白にしたコマンドは残さない)。3 秒未満で終わったら出力を読めるようキーを待つ) |
| `s` | 選んだフォルダでシェルを開く (抜けると戻って読み直す) |
| `q` `Esc` `Ctrl-C` | 終了 |

## キー (タイル)

| キー | 動作 |
|---|---|
| `j` `k` / `Ctrl-D` `Ctrl-U` `Space` / `g` `G` | スクロール |
| `Tab` | 本文中のパスを選ぶモード (`Tab` `j` `k` で選び、`Enter` で手前に重ねて開く、`e` で選んだ先をエディタで開く、`Esc` で戻る) |
| `J` `K` / `Shift-↓` `Shift-↑` | 開いたまま同じフォルダの隣のファイルへ |
| `d` | git の diff と本体を切り替える (変更のあるファイルだけ。右下に `d diff` と出る) |
| `e` | エディタで開く (木の `e` と同じ。タイルは開いたまま) |
| `o` | 外のアプリで開く |
| `O` | Finder で表示 |
| `q` `Esc` `h` `←` `Enter` | 手前の 1 枚を閉じる |

入力欄 (`/` の検索・`!` のコマンド・`:` のパス) には貼り付けられる (入力していないときの貼り付けは捨てる)。
git の印とブランチは、root と開いているフォルダが属する repo ごとに出す (root が repo の外で配下に repo が並ぶ場合も)。ブランチはカーソルの repo のもの。

Markdown は整形して、コードは言語ごとに色を付けて出す (外部コマンドは呼ばない。`tuikit/markdown` と `tuikit/highlight`)。
長い行は折り返す (設定の Wrap lines で切り替え)。
音声・画像・PDF・バイナリは開かず、toast で知らせる (画像は後で対応する。issue 688。PDF は写さない)。

## 設定

`,` の板で変えた値はその場で効き、`~/.config/treefiler/treefiler.toml` (`$XDG_CONFIG_HOME` があればその下。前の置き場 `~/.config/glogx` のファイルは初回に移す) の 1 行だけを書き換えて保存する (他の行とコメントは残す。
手で書いてもよい。形式は `key = value`)。読めない行は既定のまま使い、板の足元に何行目かを出す。
`TREEFILER_CONFIG_DIR` で置き場所を差し替えられる (テストはこれで本物を触らない)。

`Remember place` (既定で on) は、閉じたときの開いたフォルダ・カーソル・プレビューのタイルを起動したフォルダごとに
`~/.config/treefiler/treefiler-places` へ覚え、次に同じフォルダから開いたときに戻す (tmux の `C-t f` ならペインの cwd ごと)。
`q` でタイルを閉じてから `q` で抜けても、閉じたタイルを戻す (抜けたときのカーソルが閉じたタイルを開いた項目でなければ戻さない)。
