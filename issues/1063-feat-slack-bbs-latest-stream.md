# 1063 (feat): slack-bbs に、購読全体の話題を新着順に並べるタブを足す

起票日: 2026-11-11

## 概要

購読しているチャンネルとグループの話題を 1 つのタブに新着順で並べる。読む価値のある発言が増えた話題は上へ上げ、増えた分 (前に読んだ後の発言) を見せる (ユーザー要望 2026-11-11)。

## ユーザーの決定 (2026-11-11)

- 形は「話題の新着順」(案 A)。発言を 1 件ずつ流す形 (案 B) は採らない
- 既読の印はチャンネルのタブと共通にする (どちらで読んでも既読になる)
- 発言が増えて読む価値がある話題は、新着順で上に上げ、増えた分を見せる

## 今の作り (2026-11-11 に読んだ)

- タブはチャンネル (グループは 1062) ごとで、話題の並びは要対応 → 必読 → その他、それぞれ最後の発言の新しい順 (`board.Assemble` の `rank`)
- 既読の印はチャンネルごとの「単位の ID → 読んだときの単位の最後の発言の ts」(`view/read.go` の `Reads`、`cache.Read`)。
  印より後の発言が分かるので、「増えた分」は印から数えられる
- 未読は、印より後に他人の期間内の発言か他人の言及が付いた単位を持つ話題 (`view/read.go` の `unitUnread`)。自分の発言だけなら未読にしない

## 対応方針 (案)

- 先頭に「新着」のタブを足す。中身は各タブの板の話題を集めたもので、取得と分類はしない (各タブの読み直しの結果を映す)
- 並び: 未読の話題を上に、それぞれ最後の発言の新しい順。行に `#チャンネル` (グループならグループ名) と増えた件数 (`+3`) を添える
- 「読む価値がある」は今の未読の判定 (`unitUnread`) を使う。自分の発言だけ増えた話題は上げない
- 本文では、印より後の発言の前に「ここから新着」の区切りを入れ、そこへ移って開く。区切りはチャンネルのタブの本文にも出す
- 既読の付け方 (j/k で選ぶ・l で開く・o で開く・u で戻す) はチャンネルのタブと同じで、印は元のチャンネルの印に書く

## 作るときに要るもの (反証レビュー 2026-11-11 で分かった)

- **各タブの板を集めるだけでは足りない**: 起動で読むのは先頭のタブだけで、他のタブは開いたときに読む (`view/view.go` の `Init` と `switchTo`)。
  開いていないタブはキャッシュの前回の板 (`Preload`。`-no-cache` なら無い) しか無い。「新着」を出すには、全部のタブを先に読み直す (`R` と同じ。
  claude -p の呼び出しが増える) か、古い・欠けた板を断って出すかを決める。後者なら、どのタブがまだ古いかを「新着」に出す
- **行ごとに元のタブを持つ仕組みが要る**: `chanState` は 1 タブ = 1 チャンネルで、選ぶ・既読・`o`・`u` は `m.chans[m.cur]` の板・印・言及を前提にしている
  (`view/view.go` の `openSelected`、`view/read.go` の `setRead` / `toggleRead`)。`board.Topic` は自分のチャンネルを持たない。
  「新着」の行は (タブの添字, 話題) を持ち、既読の印・言及・permalink はそのタブのものを使う
- **並びは新しく組む**: `board.Assemble` の `rank` (要対応 → 必読 → その他) はタブの中の並び。「新着」はタブをまたいで並べ直す
- **1062 との関係**: グループの話題の印とキャッシュはグループの ID で持つ (1062 の決定)。印の書き先は「その話題を出したタブ」で、
  チャンネルとは限らない。同じチャンネルを複数のグループに入れてよいので、同じ発言の話題が「新着」に 2 回出うる (重複の扱いを決める)
- **増えた件数**: 印は単位ごとの最後の ts しか持たないので、数えられるのは印より後の他人の期間内の発言 (`unitUnread` と同じ条件)。
  印が無い単位は全部が増えた分になる。言及を数に入れるかを決める
- **カーソルが跳ぶ**: j/k で選んだだけで既読になる (`view/view.go` の `setRead`)。未読を上に並べると、選んだ話題が下へ動く。
  並べ直すのは読み直しのときだけにする (選んでいる間は並びを動かさない) 案が要る

## 決めること (実装の中で決め、報告で知らせる)

- タブの位置 (先頭か最後か) と、起動したときに開くタブ。開くなら全部のタブを先に読むか
- 既読の話題も並べるか (並べるなら未読の下に灰色で)
