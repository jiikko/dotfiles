# 721 (feat): treefiler の `!` のコマンドの履歴を、閉じても残す

起票日: 2026-10-12

## 概要

`!` の入力欄は ↑ / ↓ で前に打ったコマンドを呼び戻せる (`src/treefiler/filer/shell.go` の `promptState.history`)。ただし履歴は Model の中だけにあり、treefiler を閉じる (glogx の `F` を閉じる) と消える。次に開いたときも残るようにする (ユーザーの選択 2026-10-12。依頼は「! の履歴」で、起票時に既に Model の中の履歴はあると分かったので、残す方を issue にした)。

## 仕様 (案)

- 履歴をファイルに保存し、次に開いたとき読む。保存先は設定と同じ場所 (`TREEFILER_CONFIG_DIR` / `~/.config/...`)
- 件数の上限を持つ (例: 直近 200 件。古いものから落とす)。同じコマンドが続いたら 1 件にする (今の挙動と同じ)
- 単体の `bin/treefiler` と glogx の `F` で同じ履歴を使う
- 🚨 履歴にはコマンドの中身 (パス・引数) がそのまま残る。秘密を含みうるので、ファイルの権限は 0600

## 対応方針

- 書き込みは途中で落ちても壊れない形 (一時ファイル + rename)。glogx の `writeAtomic` と同じ考え方 (treefiler の places.go の保存も参考)
- 読み込みは壊れたファイル・巨大なファイルで落ちない (上限を超えた分は捨てる)
- 2 つの treefiler が同時に開いているとき (glogx を 2 つ) の上書きの扱いを決める (後から閉じた方が勝つ、で足りるか)

## 受け入れ条件

- [ ] 閉じて開き直しても ↑ で前のコマンドが出る (保存と読み込みの往復のテスト + 変異)
- [ ] 壊れた履歴ファイルで落ちない
