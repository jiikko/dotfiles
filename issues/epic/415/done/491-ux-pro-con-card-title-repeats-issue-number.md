# 491 (ux): カードの 1 行目で issue 番号が二重に出る (`C-032 #452 452: …`)

起票日: 2026-09-26

親: [415](../415-design-claude-pm-worker-orchestration.md)

## 概要

ユーザーの依頼 (2026-09-26、カード C-049): カードの 1 行目が「C-032 #452 452: 人間の操作待ち…」のように、issue 番号がバッジ (`issueTag` の `#452`) と
タイトルの頭 (`452:`) の両方に出て、2 行のタイトルの幅を食っている。

## 詳細 (2026-09-26 に読んだ)

- `src/pro-con/ui/view.go` の `cardCell`: `title := c.ID + issueTag(c) + " " + c.Title`。`issueTag` (`ui/issues.go`) は最初の issue を `#%03d` で出す (+残りの数)
- タイトルは `pro-con card add --title` で付けた文字列のまま記録に入る。カードを積む側 (人・取り込みの係・他の session) が「452: …」の形で付けている。
  既存のカードは記録にこの形で入っている (C-017〜C-047 の多く)
- 頭の形は揃っていない: `452: …` のほか、`437 の続き: …` / `456 の dispatcher 側: …` / `486 の残り: …` / `440 の未起票 2 件 (…)` がある。
  後ろの形は番号だけ落とすと意味が崩れる (「の続き」の対象が消える)
- 同じ `issueTag + " " + c.Title` を出す所は `ui/sessions.go` (セッションの一覧) にもある。タイトルだけを出す所: `ui/drawer.go` の詳細の見出し・`cardview.go` (`card show` / `card list`)・`ui/clipboard.go`・削除の確認 (`ui/model.go`)

## 決めること

1. **表示で落とすか、作るときに付けないか**:
   - 表示で落とす: 1 行目 (と sessions の一覧) で、タイトルの頭が「カードの最初の issue の番号 + `: `」と一致するときだけ落とす。記録のタイトルは書き換えない。既存のカードにも効く
   - 作るときに付けない: `card add` の案内 (pm-guide・取り込みの係への指示) で番号を付けないよう書く。既存のカードには効かない
   - 両方でもよい
2. 落とす範囲: `N: ` の完全一致だけか、`N の続き: ` のような形も扱うか (後者は番号だけ落とすと意味が崩れるので、落とさない方が安全)
3. `card show` / 詳細の見出し / クリップボードでも落とすか (これらには `#452` のバッジが無いので、落とすと番号が見えなくなる)
4. 見た目の判断が要るなら、見本 (./tmp のサンプルレンダラ) を出して人間に聞く (decide-layout-in-sample-renderer-first)

## 決めたこと (2026-09-26、C-049)

1. **両方**。表示で落とす (既存のカードに効く) + pm-guide の `card add` の項に「題名に issue の番号を付けない」を 1 行足す
2. 落とすのは「頭が数字だけ + `: ` で、その数字が**最初の** issue の番号と一致する」ときだけ (`0452: ` も同じ番号として落とす)。
   `437 の続き: ` のような形・別の番号・issue の無いカードはそのまま出す
3. `card show` / 詳細の見出し / クリップボード / 削除の確認では落とさない (バッジが無いので番号が見えなくなる)。
   落とすのはバッジと並ぶ 2 箇所 (`ui/view.go` の `cardCell` と `ui/sessions.go`) で、同じ組み立てを `ui/issues.go` の `cardHeading` に寄せた
4. 見た目は「頭の数文字が消えるだけ」で配置は変わらないので、見本は出さなかった
