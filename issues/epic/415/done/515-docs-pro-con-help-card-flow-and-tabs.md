# 515 (docs): `?` のヘルプにカードの通常の流れを書き、長くなったらタブに分ける

起票日: 2026-09-26

親: [415](../415-design-claude-pm-worker-orchestration.md)

## 概要

ユーザーの依頼: 「レーンがあるけど、どういう流れで通常はカードが流れる想定なの? help に書いといて。help が長くなったらタブを作って分けていいよ」。

今の `?` (`ui/legend.go` の `legendRows`) は、レーンごとの意味 (`card.State.Meaning`)・人の番の印・ポイント・役の仕事を並べるだけで、
**カードがどの順にレーンを渡り、誰が動かすか** (流れ) が書かれていない。

## 書くこと

- 通常の流れ: 依頼 (人が出す / issue から足す) → PM が分けて分解済みへ (`card plan`) → 空いた PG が作業中へ → PG が終えてレビューへ →
  取り込みの係が diff とテストを見て master へ取り込み完了へ。各矢印に「誰が・何で動かすか」を添える
- 寄り道: 質問待ち (PG の質問・PM が人に聞いた問い・権限の確認) から戻る先 / 差し戻し (レビュー → 作業中) / 人の番の印の出る所 /
  その場で答えて閉じる (依頼 → 完了) / 削除
- 完了の後: 1 週間で記録から消える (497)・worktree と session は人が明示したときだけ消す

## 対応方針

- 長くなるので `?` をタブに分けてよい (ユーザーの許可)。例: 「流れ / レーン / 印とポイント / 役」。タブの切り替えは設定画面 (456) と同じキー (tab) に揃える
- 🚨 `card.State.Meaning` の「レビュー」は「PM が diff と実行結果を読んでから完了にする」のままで古い (487 から取り込みの係の仕事)。同じ変更で直す
- 流れの文の正本を 1 か所に置く (`card` の側)。510 の `pro-con help` (外から動かす Claude 向け) も同じ文を使えるようにし、2 か所に書かない
- 見た目 (流れを矢印の図にするか文にするか) は見本を出して人に選んでもらう

## 受け入れ条件

- [x] `?` で通常の流れと寄り道が読め、各移り変わりに「誰が・何で」がある
- [x] 長さに応じてタブに分かれ、tab で切り替わる
- [x] 「レビュー」の説明が取り込みの係になっている
- [x] 流れの文が 1 か所にあり、510 の `pro-con help` からも使える形
