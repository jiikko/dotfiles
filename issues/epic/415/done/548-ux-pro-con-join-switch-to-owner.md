# 548 (ux): join の画面から 1 キーで持ち主の画面に切り替える (y/N で確かめる)

起票日: 2026-09-27

親: [415](../415-design-claude-pm-worker-orchestration.md)

## 概要

543 で、持ち主の画面が 1 つも無い join の画面に帯 (「持ち主の画面 (pro-con) を開くと起きる」) を出すようにした。
543 の「期待する動作」にあった任意の項目「join の画面から 1 キーで持ち主の画面に切り替える」は、2026-09-27 にユーザーが「今回は作らない」と決めたので、ここへ分けた。

今は、帯を見た人が別の端末で `pro-con` を開くか、この画面を quit して開き直す必要がある。

## 期待する動作

- join の画面で 1 キーを押すと y/N で確かめ、y なら同じ端末で持ち主の画面に切り替わる (ctrl+r の入れ替えと同じく exec で開き直す)
- 切り替わった持ち主の画面は、dispatcher が止まっていれば起こす (人が止めた印があれば起こさない = 今の持ち主の画面と同じ)

## 受け入れ条件

- [x] join の画面から 1 キー + y で持ち主の画面になり、帯が消える (キーは O。実機で確認、下の進捗)
- [x] N / esc では何も変わらない (テストは n / N / esc / 知らないキー。実機は n)

## 関連

- 543 (帯) / 481 (join の画面) / 506 (supervisor)
