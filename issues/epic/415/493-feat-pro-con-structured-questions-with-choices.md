# 493 (feat): PG の質問に選択肢を持たせ、質問待ちのカードで radio / checkbox から選んで答えられるようにする

起票日: 2026-09-26

親: [415](415-design-claude-pm-worker-orchestration.md)

## 概要

ユーザーの依頼 (2026-09-26): 「Claude Code の CLI を使っていると、質問があると選択肢が checkbox・radiobox で出るときがある。
質問待ちのレーンにあるカードに対しても、そのような UI が出るように対応したい」。

## 今の形 (2026-09-26 に読んだ)

- PG の質問は自由文 1 つだけ: `pro-con card ask <カード> "<質問>"` → `card.Wait.Question` (`src/pro-con/card/card.go`・`store/store.go` の `case "ask"`)
- PG への指示 (`dispatcher/dispatcher.go` の `Prompt`) は「AskUserQuestion を使わず card ask で聞く」。pro-con の仕組みでは AskUserQuestion の答えを届けられない (425 の実測)
- 画面の `r` (`ui/model.go`) は、どんな質問でも 1 行の自由入力の欄を開く。答えは `card answer <カード> "<回答>"` の自由文
- 実際の質問は、ほとんどが選択肢つき: 2026-09-26 の C-032 (印の形 A/B/C・する/しない が 2 問)・C-033 (明度 ×0.55 / ×0.4 と yes/no が 2 問)・
  C-042 (案 A〜D を複数選べる + コマンド名 2 択)・C-044 (A/B/C)・C-046 (3 問それぞれ推奨つき)・C-053 (3 問すべて A が推奨)。
  自由文の中に「問1 … A= / B=」と書かれ、人は読み解いて「推奨で」「a」「B」と打っていた。取り違えの余地がある (1 文字の答えがどの問いへのものか)

## 期待する動作 (案。着手前に質問する)

- **質問の形を持つ**: 1 回の ask に問いを 1〜4 個。問いごとに 見出し・選択肢 2〜4 個 (名前と説明)・複数選べるか・推奨 (任意)。
  Claude Code の AskUserQuestion と同じ形にそろえると、PG に教える形が 1 つで済む
  - 例: `pro-con card ask C-001 --json '<問いの JSON>'` か、`--question "<問い>" --option "<名前>::<説明>" … --multi` を問いごとに並べる (どちらにするかは決める)
  - 自由文だけの ask は今のまま受ける (選択肢の無い質問もある)
- **画面**: 質問待ちのカードで `r` を押すと、選択肢があれば問いごとに radio (1 つ) / checkbox (複数) の選択の画面を出す。
  j/k で選び、space で選ぶ / 外す、tab で次の問いへ、enter で送る。どの問いにも「その他 (自由に書く)」を付ける (Claude Code と同じ)。
  推奨の選択肢には印を付け、初めから選んでおく (打つ手間を減らす。変えるときだけ動かす)
- **答えの形**: 送る答えは「問いの見出し = 選んだ名前 (と自由に書いた文)」を問いごとに並べた文にし、今の `card answer` の自由文として届ける
  (PG・PM・dispatcher の側は自由文のまま読めるので、受け側を変えずに済む)。構造のまま渡すかは決める
- **ほかの読む口**: `pro-con card show` と詳細 (enter) に、選択肢を整形して出す (486 の markdown の整形と合わせる)。
  PM (`card answer --from PM`) と外の Claude は、今どおり CLI の自由文で答えてよい
- **PG への指示と pm-guide**: 選択肢のある質問は選択肢つきの ask で聞く、と書く (`dispatcher.Prompt` と、PM が PG の代わりに聞き直すときの pm-guide)

## 考えること

- 見た目 (選択の画面の形・推奨の印・狭い端末での折り返し) は本体に入れる前に見本で人に選んでもらう (decide-layout-in-sample-renderer-first)
- 選択肢の文は PG が書くので untrusted: 制御文字を落とす (termsafe)。問いと選択肢の数・長さに上限を置く
- 質問待ちのまま PG が再開で入れ替わっても、質問の形が残る (記録に持つ)。差し戻し・回答で列を離れたら消す
