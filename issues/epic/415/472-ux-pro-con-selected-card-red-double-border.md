## 概要

ユーザーの依頼 (2026-09-25): 「選択中のカードは、赤色の二重線ボーダーにできますか？」。
今の選択の枠は、現在地の色 (色 202 = 橙) の太字の太線 (`┏━┓ ┃ ┗━┛`。`src/pro-con/ui/cursor.go` の `border := fg(202) + sgrBold`)。

## 期待する動作

- 選択中のカードの枠を二重線 (`╔═╗ ║ ╚═╝`) にし、色を赤にする。赤は `docs/theme-colors.md` の定数から選ぶ (新しい番号を足すならそこへ足す)
- 選択の枠が滑る演出 (cursor.go)・端でぶつかる揺れ (bump.go。436) の間も、同じ枠で描く
- 🚨 二重線の文字は端末で幅が 1 の罫線 (U+2550〜)。幅が揺れる文字を使わない (`no-mixed-width-columns-in-terminal-ui.md`)。実際の端末に出して目で見る
- 変えるのは選択中のカードの枠だけ。選んでいるレーンの枠の色 (lanefade.go の現在地の色 202) は変えない (揃えるかは別に決める。変えないなら理由を 1 行残す)
- README の「(選択の枠)」の行と、見た目を固定しているテストを合わせる
