# 519 (ux): 終了のときにダイアログを出し、ほかの画面が開いているので何が動き続けるかを見せる

起票日: 2026-09-26

親: [415](415-design-claude-pm-worker-orchestration.md)

## 概要

ユーザーの依頼: 「閉じる時に、別の zsh でも pro-con を参照しているので、各種プロセスは残ります、という旨のダイアログを表示して欲しいね」。

## 今どうなっているか (2026-09-26 にコードで確かめた)

- `Q` で開く終了の入力欄の見出し (`ui/quit.go` の `quitLabel`) に、ほかに持ち主の画面があれば
  「ほかに N 画面が開いているので、この画面だけ閉じる。dispatcher と PG は動いたまま」と 1 行出る。最後の持ち主なら「作業中 N 本・質問待ち N 本の PG と dispatcher を止めて閉じる」
- 画面の最下段の 1 行なので見落としやすく、**どの端末の画面が残るのか**・**何が動き続けるのか**は出ない
- 数え方は `presence` (flock)。数え直すのは閉じる時点 (`StopAll`)。join の画面は持ち主に数えない (481)

## 期待する動作

- `Q` を押したら、終了の入力欄の上にダイアログ (`tuikit/confirm` の `Dialog`) を出す。中身:
  - この画面を閉じると何が起きるか: 「この画面だけ閉じる (dispatcher・supervisor・PM・PG・取り込みの係は動いたまま)」/ 最後の持ち主なら「止める」ものの一覧
  - ほかに開いている画面: 持ち主 / join の別と、端末 (tty。tmux の中なら session:window.pane に直して出す) と開いた時刻
  - 最後の持ち主で join の画面だけが残るなら、その画面は止めた後に表示が止まる旨 (今の見出しと同じ内容)
- 閉じ方 (quit と打って enter) は変えない
- 見出しの 1 行と中身を二重に持たない (文を作る所を 1 つにして、ダイアログと見出しの両方がそれを使うか、見出しを短くする)

## 対応方針

- 画面の一覧は `presence` の印の中身 (`Info`: mode・tty・pid・opened) から出す。tmux の pane への直し方は `tmux list-panes -a -F '#{pane_tty} …'` で tty を引く (無ければ tty のまま)
- 🚨 表示した「残る」の判断と、閉じた時点の判断 (`StopAll` が数え直す) は食い違いうる (ダイアログを出した後に別の画面が閉じる)。
  閉じた時点で結論が変わったら、閉じた後に main が出す文 (`KeptRunning` / 止めた) で実際の結果を出す (今の形のまま)
- 見た目は見本を出して人に選んでもらう

## 受け入れ条件

- [ ] 持ち主が 2 つのとき、`Q` でダイアログが出て、「動いたまま」とほかの画面の端末 (tmux の pane) が読める
- [ ] 最後の持ち主のとき、止めるもの (作業中・質問待ちの PG の本数・dispatcher) が並ぶ
- [ ] join の画面・見るだけの画面 (`--view`) では、それぞれ今の見出しと同じ意味の文が出る
- [ ] 見出しとダイアログで同じ文を 2 か所に書いていない
