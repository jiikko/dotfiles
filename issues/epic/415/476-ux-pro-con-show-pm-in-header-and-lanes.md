# 476 (ux): PM の数と様子をヘッダに出し、PM の仕事をレーンで分かるようにする

起票日: 2026-09-25

親: [415](415-design-claude-pm-worker-orchestration.md)

## 概要

ユーザーの質問 (2026-09-25): 「pg はヘッダーに起動数が書いているけど、pm の起動数は書いている？てか、pm の仕事ってレーンで表現できているの？」。どちらも**できていない**。

## 今の形 (2026-09-25 に読んだ)

- ヘッダ (`src/pro-con/ui/view.go`): `PG n/m` (`pgGauge`)・dispatcher の生死・`画面 N` だけ。PM の数・様子 (起動中 / 作業中 / idle / off / 起こせない理由) は出ない。
  437 の PG も残りに「画面にはまだ PM の様子を出していない」と書いた
- レーン: PM の仕事は**依頼の列** (PM の受付) にしか表れない
  - PM が今どのカードを分けている最中か (作業中) が見えない (依頼の列に置いたまま)
  - 質問待ちの列は、答えるのが PM か人間かを区別しない (452)
  - 🚨 **分解済みの列のカードが「担当: PM」と出る**: カードを作るときの既定の担当が PM (`store.go` の add: `Owner: firstNonEmpty(r.Owner, "PM")`) で、PG を割り当てるまで変わらない。
    分解済みは PG の空き待ちで PM の仕事ではないので、表示が誤っている (2026-09-25 のボードで C-013〜C-016 が「分解済み 担当: PM」)

## 期待する動作 (候補。見た目は見本で決める)

- ヘッダに `PM n/m` (動いている PM の数 / 上限。456 で人が変える) と PM の様子 (作業中のカード ID・idle・off・起こせない理由)。PG のゲージと同じ並び・同じ書式
- PM の仕事がレーンで分かる: 依頼の列のカードのうち PM が今分けているものに印 (または「分解中」の見出し) / 質問待ちは「PM の番」と「人の番」を分ける (452 と一緒に)
- 分解済みの列の担当は「PG 待ち」(または空) にする。担当は「今そのカードで手を動かす者」を出す (作った人ではない)。カードの記録の Owner の意味を決め直すか、表示だけ直すかを決める
- 読むだけ: `--view` でも出す。`pro-con card list` / `screen` (443) にも同じ
