# 499 (ux): 完了のレーンをスクロールできるようにし、スクロールバーを出す

起票日: 2026-09-26

親: [415](415-design-claude-pm-worker-orchestration.md)

## 概要

ユーザーの依頼 (2026-09-26、カード C-059): 「完了レーンでスクロールできるようにして。スクロールバーも出してね」。

## 今の形 (2026-09-26 に読んだ)

- レーンは先頭から入るだけの枚数を描き、入らない分は最後の 1 枚の代わりに「… 他 N 枚」と出して打ち切る
  (`src/pro-con/ui/view.go` の列を描く関数と `columnCells`: `items[:min(limit, len(items))]`)。先頭を動かす (オフセット) 仕組みが無い
- 選択は列の全部のカードを動ける (`ui/model.go` の `moveRow`: `min(row+delta, len(cs)-1)`)。**見えている枚数より下へ選択を進めると、選択中のカードが画面に出ない**
- スクロールバーの部品は既にある: `src/tuikit/layout/scrollbar.go` の `Scrollbar(rows, width, total, offset, colored)`。詳細の引き出し (`ui/drawer.go`) が使っている
- 完了のカードは書庫へ移るまで (478) と、完了から 1 週間で自動で消えるまで (497 / C-057) は完了のレーンに溜まる

## 期待する動作

- 完了のレーンで、選択を下へ進めるとレーンの中身が追ってスクロールし、選択中のカードが常に見えていること
- レーンに入らない枚数があるときは、レーンの右端にスクロールバーを出す (`tuikit/layout` の `Scrollbar` を使う。見た目は引き出しと揃える)。
  入り切るときは出さない
- 「… 他 N 枚」の行をどうするか (スクロールバーで置き換えるか、残すか) は決める

## 決めること

1. 完了のレーンだけか、全部のレーンにするか (列を描く関数は全レーンで共通。依頼は完了のレーンだけを名指ししている)。
   全部にするなら、移動中のカードの枠 (`m.moves`) と揺れ (`bump.go`) がスクロールした位置で正しく描かれるかを確かめる
2. スクロールの単位 (1 枚ずつか、半ページか) と、ホイール (マウス) も受けるか
3. 見た目が今の引き出しのスクロールバーと変わるなら、本体に入れる前に ./tmp のサンプルレンダラで見本を出して人に選んでもらう (decide-layout-in-sample-renderer-first)
