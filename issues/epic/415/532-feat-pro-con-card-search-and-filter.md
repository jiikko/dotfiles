# 532 (feat): カードを検索・絞り込みできるようにする (画面の / と card list)

起票日: 2026-09-27

親: [415](415-design-claude-pm-worker-orchestration.md)

## 概要

外から動かす Claude の確認 (カード C-083) に、ユーザーが issue にすると答えた。

- 画面に `/` の検索が無い。完了の列は 50 枚を超え、目当てのカードを探すのに選択を動かして目で追うしかない (499 でスクロールは入った)
- `pro-con card list` は `--state <列>` でしか絞れない (題名・issue 番号・repo・期間では絞れない)

## 期待する動作

- 画面で `/` を押すと検索の欄が出て、題名・カード ID・issue 番号・依頼の原文で絞り込める。絞っている間は印を出し、esc で戻る (キーは `docs/glogx-ui-guide.md` に合わせる)
- `card list` に題名・issue・repo などの絞り込みを足す (`--grep <文字列>` / `--issue <repo>#<番号>` など。形は PG が決めてよい)
- 見た目 (検索の欄の置き場・一致の印) は本体に入れる前に見本を出して人に選んでもらう
