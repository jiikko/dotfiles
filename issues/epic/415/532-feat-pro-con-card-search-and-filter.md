# 532 (feat): カードを検索・絞り込みできるようにする (画面の / と card list)

起票日: 2026-09-27

親: [415](415-design-claude-pm-worker-orchestration.md)

## 概要

外から動かす Claude の確認 (カード C-083) に、ユーザーが issue にすると答えた。

- 画面に `/` の検索が無い。完了の列は 50 枚を超え、目当てのカードを探すのに選択を動かして目で追うしかない (499 でスクロールは入った)
- `pro-con card list` は `--state <列>` でしか絞れない (題名・issue 番号・repo・期間では絞れない)

## 期待する動作

- 画面で `/` を押すと検索の欄が出て、題名・カード ID・issue 番号・依頼の原文で絞り込める。絞っている間は印を出し、esc で戻る (キーは `docs/glogx-ui-guide.md` に合わせる)
- `card list` に題名・issue・repo などの絞り込みを足す (`--grep <文字列>` / `--issue <repo>#<番号>` など。形は PG が決めてよい)
- 見た目 (検索の欄の置き場・一致の印) は本体に入れる前に見本を出して人に選んでもらう

## 関連

- 499 (完了のレーンのスクロール) / 531 (カードの種類) / `docs/glogx-ui-guide.md`

## 順番の見積もり (PM, 2026-09-27。C-085 を C-084 の後に積んだ)

- 触る場所: 画面のキー (`/`) と一覧の描画、`card list` の引数 (`cardview.go` / `cardcmd.go`)
- 変える判断: `card list` の絞り込みの口の形
- 順番の理由: 531 (C-084) も `card list` に種類での絞り込みを足す。絞り込みの引数の形を 2 枚で別々に決めないよう、531 の後にする

## 経過 (C-085, 2026-09-27)

- 見た目は見本 3 案 (`src/pro-con/samples/532-card-search/`) からユーザーが **案 A** を選んだ: 検索の欄は最下段 (ほかの入力欄と同じ場所)、一致しないカードは隠して上へ詰める、確定後は件数の行の頭に `/ <語> n/N 枚`、レーンの見出しは (一致/全部)
- 一致の判定は `card.Matches` 1 つにし、画面の `/` と `card list --grep` が共有する (題名・カード ID・issue 番号・依頼の原文。大文字小文字を区別しない。空白で区切った語は AND)
- `card list` に `--grep <語>` / `--issue <repo>#<番号>` (`#532` / `532` は repo を問わない) / `--repo <名前>` を足した。C-084 の `--purpose` と同じ口 (`listFilter`) にまとめ、条件はすべて AND
- 画面で絞るのはレーンの並びだけ (今のタブの中)。件数の行の列ごとの枚数と `x` の対象は絞る前のまま。絞っている間は `K` / `J` (見えている隣と入れ替わらない) と `x` (隠れた完了も片付く) を断る
- 期間での絞り込みは入れていない (期待する動作の欄に無かった)
