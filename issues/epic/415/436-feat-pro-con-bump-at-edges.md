# 436 (feat): pro-con の選択が端でぶつかったときの演出 (上下左右)

起票日: 2026-09-25

親: [415](415-design-claude-pm-worker-orchestration.md)

## 概要

ボードで一番上のカードを選んだまま ↑ を押したら「上にぶつかった」と分かる、ゴツッと出てすぐ戻る演出が欲しい。
最下部・左端・右端でも同じ (2026-09-25 にユーザーが依頼)。今は何も起きない (選択が動かない = 押したかどうかも分からない)。

## 対応方針

- 見た目は本体に入れる前に見本で決める (`~/.claude/rules/decide-layout-in-sample-renderer-first.md`)。見本を用意した (使い捨て、commit しない):
  `python3 ~/dotfiles/tmp/pro-con-bump-sample.py [A|B|C] [ms]`
  - A: 選択の枠が壁の方へ少し出て (1 行 / 2 桁)、減衰しながら跳ね返って戻る
  - B: A + ぶつかった壁 (列の枠の辺) が一瞬赤く光る
  - C: 列ごと小さく揺れる
  - 既定 500 ms。約 75 ms で出きって、跳ね返りながら戻る
- **ユーザーの選択待ち** (A / B / C と長さ)。決まったら ui/cursor.go の枠の滑り (cursorGlide) に「ぶつかる」を足す。
  端の判定は moveRow / moveCol / jumpCol が動かなかったとき (空のレーン・カード 1 枚の列も含む)
- 好み (記録): 操作のメタファー + 600 ms〜1 s + 主役を高コントラスト (memory の tui-animation-taste)。ぶつかる演出は短い方が合うかもしれないので、長さも見本で決める
