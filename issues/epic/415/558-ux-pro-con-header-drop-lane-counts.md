# 558 (ux): ヘッダの行からレーンごとのカード数 (依頼 0 … 完了 6) を消す

起票日: 2026-09-27

親: [415](415-design-claude-pm-worker-orchestration.md)

## 概要

人間の依頼 (2026-09-27、pro-con カード C-010) の原文:

> 画面のヘッダ 3 行目の先頭にある「依頼 0  着手待ち 0  作業中 2  質問待ち 0  レビュー 1  完了 6 │」の部分を消して (人間の依頼)。
> 各レーンの枠の見出し (「3 作業中 (2)」など) に同じ数が出ていて無駄。同じ行の残り (最古の待ち │ PG 2/2 │ PM 1/1 │ dispatcher … │ 起動時 … │ 新版あり など) はそのまま残す。
> レーンの枠の見出しの数も残す。幅の狭い端末でも残りの項目が崩れないことを確かめる

## 今の形

- `src/pro-con/ui/view.go` のヘッダの行 (365 行付近): `card.Columns` ごとに `st.Label() + 件数` を並べ (`parts`)、その後に
  絞り込みの印 (`searchMark`)・人の番 (`humanTag`)・最古の待ち・`pgGauge`・`pmGauge` … を `│` で繋ぐ
- 件数を数える `counts` は、ほかに使われていなければ一緒に消す (人の番・pending・stalled の数え上げは残す)

## 受け入れ条件

- [ ] ヘッダの行からレーンごとの件数が消え、行は残りの項目 (絞り込みの印・人の番・最古の待ち・PG・PM・dispatcher・起動時・新版あり 等) から始まる。先頭に余分な `│` や空白が残らない
- [ ] レーンの枠の見出しの数 (「3 作業中 (2)」) は残る
- [ ] 幅の狭い端末でも残りの項目が崩れない (見本か描画のテストで幅を変えて確かめる)
- [ ] README / `docs/glogx-ui-guide.md` 等にヘッダの件数の説明があれば直す

## 並行するカードとの衝突の見積もり (PM)

- C-007 (557) がヘッダの同じ行の「PG n/枠」(`pgGauge`) を dispatcher の書いた値に寄せる。同じ行の組み立てを変えるので **C-007 の後に積む** (`--after C-007`)。
  取り込みの係は、557 の「PG 作業中 n / 枠 · 待機」の表示が、件数を消した後の行の頭で崩れないかを見る
