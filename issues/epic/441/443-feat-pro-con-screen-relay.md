# 443 (feat): 画面の中継 — 人間の画面に今出ているものを外の Claude が読む

> 🚨 **担当中: dotfiles-7d**（2026-09-25〜）

起票日: 2026-09-25

親: [441](441-design-pro-con-viewer.md)

## 概要

人間の pro-con の画面に今何が出ているか (ボード・ゲージ・通知・入力欄の見出し・開いている詳細) を、外の Claude が文字として読む。
画面の不具合を「人間に見えている形そのもの」で調べられるようにする (今は隔離した tmux で同じ形を作り直して撮るしかない)。

## 対応方針 (候補)

- 画面は描くたびに最新の 1 枚 (文字・色を落とした版と、そのままの版) と画面の状態 (タブ・選択・モード) を、状態の置き場の
  `screens/<id>.frame` に置く (上書き。書きかけを読ませない)。描画は待たない (441 の守ること 3)
- `pro-con screen [--screen <id>] [--follow] [--ansi]` が読む。複数の画面が開いていれば一覧を出す (画面の id は package presence の印)
- 入力欄に打ちかけの文も出る (同じユーザーだけが読める前提。445 で扱う)
