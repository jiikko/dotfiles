# 496 (feat): ほかの画面が選んでいるカードを、ボードに薄い印で出す (共同で使うときに、誰がどこを見ているかが分かる)

起票日: 2026-09-26

> ⏸ **保留 (2026-09-26〜)**: ユーザーの判断「複数の人間が見ることはなく、せいぜい僕と Claude が共同で使うだけ」。
> 画面を開くのは人 1 人と Claude の session で、Claude は画面ではなく `pro-con card` / `pro-con screen` で読み書きするので、
> 「ほかの画面が選んでいるカード」を人が気にする場面が今は無い。**再開の条件**: 複数の人が同時に画面を開いて使うようになったとき

親: [441](../441-design-pro-con-viewer.md)

## 概要

481 (共同で読み書きする画面 `pro-con --join`) の spec の 6 番目で範囲外にした項目。481 の「残したもの」から切り出した。
画面を複数開いて共同で使うとき、ほかの画面 (持ち主 / join) が今どのカードを選んでいるかを、自分のボードに薄い印で出す。
同じカードへ 2 つの画面から同時に答える・差し戻す、を起こす前に気づけるようにする (重なったときの断りは 481 で入った)。

## 今の形 (2026-09-26)

- 画面は開いている間 `screens/<id>.lock` を flock で持ち、印にモード・`--as` の名前・端末・pid・開いた時刻を書く (481。`presence`)。
  選んでいるカードは印に書いていない
- ゲージに画面の一覧が出る (「a1b2c3 持ち主 (この画面) · d4e5f6 join review」)

## 期待する動作 (案)

- 各画面が選んでいるカードの ID を、自分の印に書き足す (選択が変わるたびに。書く頻度に上限を置く)
- ボードで、ほかの画面が選んでいるカードに薄い印 (例: 枠の色・`--as` の名前の頭文字) を出す。自分の選択の枠 (cursor.go) と見分けられる形
- `--view` の画面は印を書かないので出さない (presence に入らない)
- 見た目は本体に入れる前に見本で人に選んでもらう
