# 443 (feat): 画面の中継 — 人間の画面に今出ているものを外の Claude が読む

起票日: 2026-09-25

親: [441](../441-design-pro-con-viewer.md)

## 概要

人間の pro-con の画面に今何が出ているか (ボード・ゲージ・通知・入力欄の見出し・開いている詳細) を、外の Claude が文字として読む。
画面の不具合を「人間に見えている形そのもの」で調べられるようにする (今は隔離した tmux で同じ形を作り直して撮るしかない)。

## 対応方針 (候補)

- 画面は描くたびに最新の 1 枚 (文字・色を落とした版と、そのままの版) と画面の状態 (タブ・選択・モード) を、状態の置き場の
  `screens/<id>.frame` に置く (上書き。書きかけを読ませない)。描画は待たない (441 の守ること 3)
- `pro-con screen [--screen <id>] [--follow] [--ansi]` が読む。複数の画面が開いていれば一覧を出す (画面の id は package presence の印)
- 入力欄に打ちかけの文も出る (同じユーザーだけが読める前提。445 で扱う)

## 進捗

- 2026-09-25 (dotfiles-7d): 実装した (commit「feat(pro-con): 画面の中継 — pro-con screen で人間の画面に今出ているものを外から読む (issue 443)」)

### 受け入れ

- [x] 画面は描くたびに最新の 1 枚を `relay/<id>.frame` に置く (package relay)。画面が開いている間は `relay/<id>.lock` を flock で持つ。
      置き場は presence (`screens/`) と別: 見ているだけの画面 (--view) は presence の印を置かないが、中継はする
- [x] 描画を待たせない (441 の守ること 3): View は受け口 (ui.FrameSink) に描いた文字と状態を渡すだけ。relay.Writer.Put は最新の 1 枚をメモリに置いて戻り、
      書き出しは別の goroutine が最短 100ms ごとに最新だけを書く。中身 (文字・大きさ・状態) が同じ描き直しは書かない
- [x] `pro-con screen [--screen <id>] [--all] [--ansi] [--json] [--follow [--timeout]] [--e2e <置き場>]`: 開いている画面が 1 つならそれを、複数なら一覧を出す。
      既定は色を落とした文字。状態 (mode / tab / selected / 開いている詳細) と大きさも出す
- [x] 入力欄に打ちかけの文も伏せずに中継する (2026-09-25 にユーザーが決めた。445)
- [x] 自分だけ (守ること 2): relay/ は 0700 (symlink なら使わない)、ファイルは 0600。書きかけは読ませない (一時ファイル + rename)
- [x] 読み取りだけ (守ること 1): `TestScreenDoesNotWrite` (screencmd_test.go) が、pro-con screen の前後で置き場のファイルの中身・mtime・数が変わらないことを見る。
      読む側は flock を読むだけで開き (O_RDONLY)、何も消さない
- [x] 落ちた画面 (端末を閉じた・kill -9) の残りは、次に開く画面が片付ける (flock の外れた印・その 1 枚・印の無い 1 枚・1 分より古い一時ファイル)。
      ライブアップグレードは exec の前に中継を閉じ、失敗して戻ったら開き直す

### 記録のみ (直していない / テストが無い)

- 印を一時名で作ってから rename する直し (読む側の flock との競合) は、競合の窓が µs でテストで作れない。コードで確かめただけ
- exec の前に中継を閉じる・失敗で開き直す、はテストが無い (e2e はライブアップグレードを通らない)
- writeAtomic を直書きに替える (書きかけを読む) 退行と、受け口を同期の書き出しに替える退行を捕まえるテストが無い
- カーソルの位置は中継に載らない (ANSI にも状態にも入らない。入力欄の ←/→ だけの変化は書かれない)
- 書き込みが固まる FS では、Close (quit・アップグレードの前) が書き出しの途中を待って固まりうる (ローカルの FS では起きにくい。未確認)
- relay/ を途中で symlink に差し替えると、その先の *.lock / *.frame を片付けうる (同じユーザーの書き込みが要る)
