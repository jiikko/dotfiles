# 686 (feat): 資料の語り方のモードを台本のキーにし、独自調査のモードで資料の存在が漏れていないかを lint で見る

> 🚨 **担当中: epic 674 を直列で進めているセッション**（2026-10-08〜）

起票日: 2026-10-08

## 概要

資料の語り方のモード (資料を明かす / 独自調査。SKILL.md の「資料の語り方」) は、今は手順 0 で聞いて、台本には残らない。
独自調査のモード (不特定多数に公開する動画) で、セリフ・`title`・`description` に「資料」「レポート」「回答」などが出ていないかは、
確認役が目で見ている。元の資料は非公開になることがあるので、漏れると取り返しがつかない。

## 対応方針 (案)

- 台本に `"source_mode": "public"` のようなキーを足し、手順 0 で聞いたモードを書く (省略は資料を明かすモード)
- lint (675) が、独自調査のモードの台本で、セリフ・`title`・`description` に元の資料の存在が分かる語 (資料・レポート・回答・この文書・AI の分析)
  があれば警告する
- 「資料」という語を本来の意味で使う行もありうるので、止めるか警告にするかは誤検出を測ってから決める
- 台本のキーを足すので、`script.go` の台本の検査と SKILL.md の台本 JSON の表を直す。プレイヤーのデータには載せない (見た目は変わらない)

## 受け入れ条件

- [x] 独自調査のモードの台本で、資料の存在が分かる語を含む行が出る (警告ではなく目安。下の「止めるか警告か」)
- [x] 資料を明かすモード (省略時) では出さない
- [x] 規則を外す変異で red になる (19 本)
- [x] SKILL.md の手順 0 で、聞いたモードを台本のキーに書くことを書く

### 止めるか警告か (対応方針の「誤検出を測ってから決める」)

**目安 (rc に効かない) にした**。2 周目の敵対レビューで、IT/SI 解説の台本 (公開文献を名前で引く台本) を独自調査のモードにして流すと、
警告にしていた「レポート」2 件は「経産省の DX レポート」という正当な引用で、本当の漏れの「AI の回答」は目安側に落ちていた。
SKILL.md は公開された文献を名前で引くよう求めており、字面では漏れと区別できない。漏れかどうかは手順 3-3 の確認役が lint の一覧を見て決める。
**行ごとに抑止できる口ができたら、警告へ戻せる** (lint.go の `sourceLeakRe` のコメント)。
