## 概要

事実の確認 (手順 3-3) と「資料の外から足した行」の報告 (手順 3-4) は、今は確認役と main が台本を全行読んで行う。
台本と資料を機械で突き合わせて候補の一覧を出せば、人と確認役は一覧だけを判断すればよくなる。判断は機械でなく人と確認役が行う
(候補には正しいものも混ざる)。

## 候補の一覧

| 一覧 | 効き目 |
|---|---|
| 台本の数字 (`95.03%`・`2026年`・`4つ`) のうち、資料に現れないもの | 数字の誤りを確実に拾う。2026-10-08 の試験で仕込んだ「85.03%」(資料は 95.03%) はこれで拾える。ただし確認済みの外の事実 (Linux 3.05% など) も載るので、確認済みの事実の一覧と合わせて見る |
| 台本の英字の語・固有名詞のうち、資料に現れないもの | 手順 3-4 の「資料の外から足した行」の下書きになる |
| 重要語の図解 (`keyword`) の語が、図解の出ている区間のセリフに出てこない | 図解とセリフの対応の確認の一部。比較の項目は言い換えが多いので対象にしない |
| 導入と本題の境目 (2 つ目のチャプターの直前の行) に区切りの語 (「本題」等) が無い | 導入と本題を会話で区切る決まり (2026-10-08 にユーザーの指摘で SKILL.md に足した)。言い方が自由なので候補どまり |

## 対応方針 (案)

- 資料は Markdown などのテキストで渡す (今の手順でも、資料を取得して作業ディレクトリに置いている)。PDF などは対象外にするか、テキストにしてから渡す
- 数字は表記を揃えて比べる (全角・半角、「4つ」と「四つ」、「95.03%」と「95.03 %」)
- 出力は警告ではなく一覧 (rc は変えない)。lint (675) のサブコマンドに入れるか、別にするかは決める
