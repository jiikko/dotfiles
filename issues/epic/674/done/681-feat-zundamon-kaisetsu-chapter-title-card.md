# 681 (feat): チャプターの頭に区切りのカード (大きな見出し) を出す

起票日: 2026-10-08

## 概要

チャプターが変わっても、画面の上部中央のトピック名が切り替わるだけで、区切りが目に入りにくい。

## 根拠

2026-10-08 の Mac vs Windows を見たユーザーの指摘: 導入から本題へ「ヌッと移動していた」。台本の側は、導入の最後に会話で区切る
書き方を SKILL.md に足して直した (同日)。画面の側でも区切りが見えると、さらに伝わる。

## 対応方針 (案)

- チャプターが始まる行の最初の 1〜2 秒、舞台の中央にチャプター名を大きく出す (トピック名と同じ文字を使う。台本に書くことは増やさない)
- 🚨 mp4 は「見た目の状態」ごとに撮るので、カードの出ている間を状態として持つと撮る枚数が増える。増え方を実測してから決める
  (まばたきで状態は 1.8 倍に増えた。SKILL.md の仕組みの節)。図解 (`show`) と同時に出るときの重なりも決める
- `overlays` のように、出すかを選べるようにするかも決める
- 見た目はサンプルを撮ってユーザーに見せてから決める

## 制約

- Go と player.html の 2 か所にある契約 (src/zundamon-kaisetsu/CLAUDE.md) に触れる。状態の列を足すなら `#sheet=` の欄
  (`sheetFragment`) と player の両方を変える。golden の `frames` を変えないよう、まばたきと同じく別の列に持つ
- 出すかを `overlays` で選べるようにするなら、`overlayKeys` と player の `OV` の契約に足す

## 受け入れ条件

- [x] 見た目の案を撮って見せ、決めてから本体に入れる
- [x] mp4 の撮る状態の数と build の時間の増え方を、実測して書く

## 進捗

### 見た目の決定 (2026-10-08)

過去の動画のコマを背景に 3 案 (白いカード / 横幅いっぱいの青い帯 / 枠なしの大きな文字に青い下線) を撮って見せ、
**枠なしの大きな文字に青い下線** (「CHAPTER 番号」+ チャプター名) に決まった。

### 実装 (commit: zundamon-kaisetsu: チャプターの頭に区切りのカードを出す (issue 681))

- `chapter_card.go` の `chapterCardRuns`: チャプターの頭から 1.5 秒 (`chapterCardSeconds`) を「カードを出す」フレームの列にする。
  出す条件はトピック名と同じ (チャプター 2 つ以上・`overlays` に `topic`)。`overlays` に新しいキーは足していない (トピック名と同じ情報なので、`topic` で一緒に出し入れする)
- プレイヤーのデータに `cards` を足した (まばたきと同じく golden の `frames` を変えない別の列。`keysAddedAfterPort`)
- mp4: 見た目の状態を 5 欄 (行・話し中・口・まばたき・カード) にした。`#sheet=` の断片・状態の絵のファイル名も 5 欄
  (ファイル名を 4 欄のままにすると、カードの有無だけ違う 2 つの状態が同じ絵になる)
- player.html: カードを出している間は、上部のトピック名と図解を隠す (中央で重なるため)。長いチャプター名は文節で折り返す

### 実測 (Mac vs Windows の台本。73 行・405.8 秒・チャプター 6 つ。M3 Max・1 回ずつ)

| | 変更前 | 変更後 |
|---|---|---|
| 見た目の状態 | 550 | 568 (+3%) |
| Chrome の起動 | 28 回 | 29 回 |
| build (html + mp4) | 64 秒 | 167 秒。うち 1.8 分は CPU の混雑待ち (load 30.8 / 14 コア) で、待ちを除くと約 59 秒 |

mp4 の各チャプターの頭のコマと、HTML の再生 (`#t=90.5`) の画面を撮って、カードが出てトピック名が隠れ、1.5 秒後に戻ることを目で確かめた。
