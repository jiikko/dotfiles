# 682 (feat): 驚き・怒りなどの演出を、止まった絵の重ねで足す

> 🚨 **担当中: epic 674 を直列で進めているセッション**（2026-10-08〜）

起票日: 2026-10-08

## 概要

表情は 8 種類あるが、感情の強い場面 (驚き・怒り・悲しみ) でも立ち絵の表情が変わるだけで、画面の動きが少ない。

## 対応方針 (案)

- 表情 (`face`) に合わせて、立ち絵の後ろか上に止まった絵を 1 枚重ねる (驚き: 集中線、怒り: 怒りマーク、悲しみ: 青い縦線 など)
- 🚨 **動く演出 (揺れ・跳ね) は入れない**。mp4 はコマごとの見た目の状態を撮るので、動きのコマの数だけ撮る枚数が増える
  (まばたきだけで状態は 1.8 倍、build は 45 秒から約 57 秒に延びた)。止まった絵なら、表情と同じ状態に収まり、撮る枚数は増えない
- 重ねる絵の素材の出どころと規約を決める (立ち絵とは別の素材になる)
- 見た目はサンプルを撮ってユーザーに見せてから決める

## 制約

- Go と player.html の 2 か所にある契約 (src/zundamon-kaisetsu/CLAUDE.md) に触れる。状態の列を足すなら `#sheet=` の欄
  (`sheetFragment`) と player の両方を変える。golden の `frames` を変えないよう、まばたきと同じく別の列に持つ
- 重ねる絵を HTML に埋め込むので、プレイヤーのデータ (golden と比べるキー) に足すキーは `keysAddedAfterPort` に挙げる

## 受け入れ条件

- [x] 見た目の案を撮って見せ、決めてから本体に入れる
- [x] mp4 の撮る状態の数が増えないことを実測で確かめる
- [x] 素材の規約とクレジットの表記を決めて書く (自前で描いた SVG なので、別の素材の規約もクレジットも無い)

## 進捗

### 見た目の決定 (2026-10-08)

過去の動画のコマに 3 つの演出 (驚き = 集中線・怒り = 怒りマーク・悲しみ = 青い縦線) を重ねた見本を見せ、3 つとも採用になった。

### 実装 (commit: zundamon-kaisetsu: 驚き・怒り・悲しみの表情に止まった演出を重ねる (issue 682))

- player.html だけで完結した (Go の変更なし)。立ち絵の表情を `data-fx` に書き、CSS で演出を 1 つだけ見せる。
  表情は見た目の状態の「行」に含まれるので、プレイヤーのデータも状態の欄も増やしていない
- 演出の位置を立ち絵の画像に合わせるため、img を `.fig` で包み、画像の上限を箱の % から舞台の幅 (cqw) に書き換えた。
  最初の版は箱 (舞台の高さの 96%) を基準にしていて、怒りマークと縦線が頭より上に浮いた (撮って見つけた)
- 怒りマークは頭の内側 (画面の中央寄り) に置く。外側は図解のある台本で舞台の端に寄って切れる
- 集中線は立ち絵の後ろ (`.char` の `isolation: isolate` の中で z-index -1)

### 実測・確認

- mp4 の撮る状態: Mac vs Windows の写し (5 行の表情を怒り・悲しみ・驚きに変えた台本) で、演出を入れる前も後も 559 種類・Chrome 28 回
- 演出の無い状態の画素は変更前後で同一 (720p のまとめ撮りで、図解ありの台本 2 本と図解なしの台本 1 本を比べた)
- 図解あり (立ち絵が小さい) と図解なし (立ち絵が大きい) の両方で、3 つの演出が頭・顔の位置に出ることを撮って確かめた
