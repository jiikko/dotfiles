# 801 (feat): 画面共有と並べて ssh を張り、相手の Mac の出来事を拾ってアプリに反映する (リアクティブな動作)

起票日: 2026-10-16

> epic 793 の子。画面共有の本体は 796、常時接続と切り替えは 798。

## 要望 (ユーザーの言 2026-10-16)

「自作アプリでは画面共有と ssh の両方にしておいて、ssh 経由で polling として、画面共有先のイベントを拾って、ssh 経由で操作を進めるとか、
共有先でのイベントを ssh 経由でキャッチアップをして、自作アプリのメインウィンドウに反映するみたいなことをしたい。詳細はまだ思いついていないが、
リアクティブな動作をさせたい」

## 何をしたいか (今の理解。詳細はまだ決まっていない)

- 繋いでいる Mac ごとに、画面共有 (見る・触る) と ssh (状態を読む・コマンドを打つ) の 2 本を張る
- ssh で相手の Mac の出来事を拾い、アプリのメインウインドウ (一覧) に反映する。拾った出来事をきっかけに、ssh で次の操作を進める
- 画面を見ていない Mac でも、何が起きたかが一覧で分かる (常時接続の 798 と組み合わせる)

## 作り方の案

- **polling より push を先に考える**: 長く張った ssh の中で `log stream` や小さな監視のスクリプトを走らせ、1 行ずつ受ける。
  polling は、変化を待つ口が無いものだけに使う (間隔は出来事ごとに決める)
- 相手ごとに ssh の接続を 1 本に束ねる (ControlMaster か、アプリが持つ 1 本の接続の上に複数のチャネル)。コマンドのたびに鍵の交換をしない
- 相手側で何を走らせるかは、決めた 1 か所 (相手に置く小さなスクリプトか、毎回送るコマンドの組) にまとめる。ここが太ると 795 の系統 2 (相手に自作のサーバを置く) に近づく
- 鍵の設定は 747 (mac-lan-manager の初期設定) が済ませる前提。747 から受け渡す (797) ときに、ssh の宛先 (ユーザー・IP・HostKeyAlias) も渡す
