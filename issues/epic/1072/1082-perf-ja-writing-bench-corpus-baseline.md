読み取れること (A の数字から)

- lint の処理は長さにほぼ比例する (64 KB → 1 MB の 16 倍で 0.064 → 0.555 秒の 8.7 倍)。4 KB では処理 0.020 秒に対し起動が 0.079 秒で、所要の 8 割は起動
- 同じ長さ (64 KB) では、同じ段落の繰り返しが最も速く (0.033 秒)、長い 1 行は半分の長さで 64 KB の文書の 0.8 倍かかる (0.051 秒)
- diff は 64 KB → 256 KB (入力 4.0 倍) で処理が 3.0 倍。check は中で lint と diff を子プロセスで起こすので、small でも処理が 0.32 秒ある (子プロセスの起動が入る)
- 1 回目と 2 回目で全ケースが同じ向きに 10〜21% ずれた。Go の側と比べるときは、別の時間帯の run どうしで比べず、同じ run の中で交互に流す (1079 の後半で pybench.sh に Go のケースを足す形)
