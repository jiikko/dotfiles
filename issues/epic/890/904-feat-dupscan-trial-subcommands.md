# 904 (feat): dupscan を人が試す入口 (near・explain・gate の試し方)

起票日: 2026-10-24

## 概要

dupscan は、主に Claude が書く前に索引を引き (897)、セルフレビューと `make test` で `dupscan gate` を回す ([905](905-feat-dupscan-ci-check-gate.md))。人が日常的に使う道具ではないが、
**動作確認として「何ができるか・なぜ同じと判定したか」を人が手で試せる入口**が要る (ユーザー 2026-10-24)。
重複の報告 ([896](896-feat-dupscan-report-output.md)) と索引 ([897](897-feat-dupscan-index-subcommand.md)) は repo 全体を相手にするので、
1 つの関数を指して試す入口を 2 つ足し、`gate` を手で試す方法を書く。どれもコア (893・894) と同じ単位の一覧の上に載せ、判定の実装を別に持たない。

| subcommand (名前は仮) | 入力 | 出力 | 何を確かめるか |
|---|---|---|---|
| `dupscan near <file>:<関数名>` (`<file>:<行>` も可) | 1 つの単位 | その単位に近い既存の単位を、一致した段 (Type-2 の L1 / L2 / L3) ごとに並べる。リテラルの違いの表も付ける | 「この関数に似たものは既にあるか」 |
| `dupscan explain <file>:<関数名>` | 1 つの単位 | 段ごとに潰した形 (L1 の番号付けの後・L2 のリテラルの記号化の後・L3 の畳み込みの後) と各段のハッシュ。外れたなら理由を区別して出す (読めない構文 / 大きさの下限 / L3 で本体全体が 1 記号に畳まれた単位の別扱い) | 「なぜ同じ / 違うと判定したか」。閾値や正規化を直すときの手がかりにもなる |
| `dupscan gate` を手で回す (905 の command そのもの。`--base <ref>` で base を変えられる) | 今の作業ツリー | `make test` で落ちるときと同じ違反の一覧と、新しく足された許可の一覧 | 「`make test` に入れたら、何で落ちるか」。わざと写しを書いてから回すと、落ち方が見える |

- 出力は人が読む形を既定にし、`--json` も出す (テストと、Claude が読むとき用)。JSON の形は 896 の組の JSON とそろえ、別のスキーマを作らない
- `near` は、`gate` (905) と同じ「ある単位と同じ段のハッシュを持つ他の単位を探す」関数を呼ぶ (人が試した結果と、`make test` の結果が食い違わないように)
- **指した単位そのものは結果から外す**。鍵はファイル + 名前・署名。`<file>:<行>` で指したときは、その行を含む単位を探してから同じ鍵で外す
- 🚨 PR 24 の 6 つのように本体で引数を使わない単位は、L3 で本体全体が 1 記号に畳まれ、同じ型を返す引数なしの単位がどれも一致しうる ([891](891-design-dupscan-requirements.md) の L3、[898](898-test-dupscan-obaket-calibration.md) の否定の期待値)。
  `near` はこの一致を、中身を見た一致と区別して出す (`explain` でも畳まれたことが見える)
- 単位を名前で指したとき、同じファイルに同名の単位が複数あれば (overload など) 候補を列挙して止める (黙って片方を選ばない)

## 受け入れ条件

- [ ] obaket の PR 24 の前の木 (commit 45cc3b208^) で、6 つのうち 1 つを `near` で指すと残りの 5 つが段つきで出る
- [ ] `explain` で、直書きの版とプロパティを読む版の L3 のハッシュが一致し、L1 / L2 では違うことが見える。引数を使わない単位なら、L3 で本体全体が 1 記号に畳まれたことが見える
- [ ] `near` と `gate` が同じ照合の関数を通すことをテストで固定する
- [ ] `near` の結果に、指した単位そのものが出ない
- [ ] 無関係な関数を `near` で指すと「近いものはない」と出る (否定の期待値。898 で決めた L3 の扱いの上で)。読めない構文の単位を指すと、外した理由が出る
- [ ] `bin/dupscan` の usage と `src/dupscan/README.md` に、`near`・`explain` と `gate` を手で試す例 (わざと写しを書いて落ちるのを見る) を書く (試す人がたどり着ける入口のドキュメント)
