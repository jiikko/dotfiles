# 902 (feat): Claude Code が編集している最中に、近い既存のメソッドを知らせる (hook と探索の入口)

起票日: 2026-10-24

## 概要

epic 890 の主な用途 (ユーザー 2026-10-24): **Claude Code にコードを変更させている間に、重複したメソッドを作らせない・
既存のメソッドを見つけやすくして実装を滑らかにする**。[901](901-research-dupscan-existing-tools.md) の調査では、
これを自動でやる組み込みを持つ道具は見つからなかった。2 つの時点で効かせる:

1. **書く前 (探す入口)**: 名前で引く (Claude Code の LSP ツールの `workspaceSymbol`・Serena) と、形・用途で引く (dupscan の索引。[897](897-feat-dupscan-index-subcommand.md)) を、
   新しいメソッドを書く前に使う手順として、使う側の repo の入口 (CLAUDE.md・skill) に書く
2. **書いた直後 (知らせる)**: PostToolUse (Edit / Write) の hook で、編集されたファイルの中の新しい・変わった単位だけを取り出し、
   repo の索引と比べる。近いもの (Type-2 の一致・L3 の一致) があれば、名前・file:line・どの段で一致したかを返す。既定は止めずに知らせるだけ

## 要件

- **所要**: hook は編集のたびに走る。索引はキャッシュし、編集されたファイルだけを parse する。上限の目安は未実測 (受け入れ条件で測る)。
  索引が古いとき (他の変更・他のセッション) に、古いまま比べたことを分かる形にする
- **知らせる内容**: 既存の単位の名前と署名・file:line・可視性・doc comment の 1 行目・一致した段。共通の置き場所にあるものは「これを使う」、
  ファイルの中の private なものは「寄せる候補」と区別する。件数に上限を置く (多すぎると読まれない)
- **黙らない**: 索引が無い・読めない構文・道具が無いときは「確認できなかった」と返す。沈黙を「重複なし」に読ませない
- **hook の出力の拘束力**: hook が返す文は背景情報 (`<system-reminder>`) として届き、指示ほど強くない (dotfiles の `CLAUDE.md`「`_claude/` を触るとき」)。
  知らせても使われないことがあるので、書く前に探す手順 (1) を入口に置くのと組にする
- **opt-in**: 使う側の repo が settings の hook で有効にする。置き場所 (dotfiles の `_claude/hooks/` か、使う側の repo か) は決めること

## 受け入れ条件

- [ ] 無関係な編集で何も返さない (否定の期待値)
