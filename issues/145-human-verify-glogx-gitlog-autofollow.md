# glogx: git log 表示中の自動追従を目視で確認する

期限: 2026-09-08

`src/glogx/gitlog_watch.go` で「git log を表示している間、別プロセスの変化を反映する」機能を
入れた。ロジック・チェーンの規律・錨の画面行の保持は Go のテストで固定してあるが、
**手触り (どのくらいで来るか / 演出が邪魔にならないか / トーストの文言)** は人が見るしかない。

## 確認してほしいこと

`glogx` を開いたまま、別ターミナル (または Claude Code) で下の操作をする。

- [ ] **カーソルが先頭のとき**に commit → 新規行が上から降ってきて、カーソルは先頭に残る。
      右下に「新しいコミット N 件」が出る
- [ ] **カーソルを途中まで動かしてから** commit → 見ているコミットが**同じ画面行に残る**
      (行が下へずれない)。トーストは出る
- [ ] 反映までの体感が数秒以内 (fsnotify のイベント + 1 秒のデバウンス)。遅すぎ / 速すぎで
      気が散らないか
- [ ] `git commit --amend` / `git rebase -i` (数コミットまとめて) をしても、途中の状態で
      チカチカ反映されない (1 秒の静穏で畳んでいる)
- [ ] `d` で diff ポップアップを開いている間に commit → その場では反映されず、閉じた後に
      反映される (最悪 1 分待つ。長すぎると感じたら周期を見直す)
- [ ] glogx 自身の `u` (pull) / `b` (push) の直後に、余計なトーストや二重のリロードが出ない
- [ ] 別ターミナルで `git fetch` して origin/* が動いたとき (decoration が変わる)
- [ ] `git commit --amend` したときのトーストが「新しいコミット 1 件」になる (書き換えなのに
      「新しい」と出る。気になるなら文言を分ける)
- [ ] issues viewer / status viewer / 残量ダッシュボード (`R`) を開いている間は反映されず、
      閉じた後に反映される (最悪 1 分待つ)

## 気になったら報告してほしい点

- トーストの文言 (「新しいコミット N 件」/ 変化だけのときの「git log を更新しました」)
- デバウンス 1 秒 / 保険のポーリング 1 分の値
- 途中を読んでいるときに「新しいのが来た」と気づけるか (行が動かないので、トーストだけが手がかり)
