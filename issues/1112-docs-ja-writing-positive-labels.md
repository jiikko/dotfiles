# 1112 (docs): ja-writing に「状態や区分の語は肯定形で書く」を足す

起票日: 2026-11-26

## 概要

状態・区分・表の見出しの語を、否定形（「論理削除されていない」「対象外」）でなく肯定形の単語（「有効」「使用中」）で書く、という規範を `_claude/skills/ja-writing/SKILL.md` に足す（ユーザー指示 2026-11-26）。

## 詳細

起点は、別の業務の repo で画像を物理削除にする作業をしたときの説明。

- 画像の仕分けを説明するときに、行の状態を「論理削除されていない / 論理削除済み」と否定形の語で並べた。ユーザーから「否定形じゃなくて、基本的に肯定系で単語を書く」と指摘された
- 同じ説明で、仕分けのラベルが 3 つ（使用中・不使用・新規）と決まっているのに、ラベルに無い「対象外」を持ち込んで説明した。ユーザーに「対象外って何。3 つのラベルで語ってくれ」と聞き直された
- その前にも、仕分けのラベルを「残す・消す・足す」と動作の語で書いていて、「残すっていう名称がわかりにくい」と言われ、状態の語（使用中・不使用・新規）に直した

否定形の語は、何であるかを言わずに「何でないか」だけを言うので、読み手が残りの集合を自分で組み立てることになる。並べた区分の片方だけが否定形だと、表の見出しとしても読みにくい。

## 対応方針

- `SKILL.md` の規範に 1 節足す（規範 8 の否定対比の近く）。中身の案:
  - 状態・区分・ラベル・表の見出しは肯定形の単語で書く（`論理削除されていない` → `有効` / `生きている行`、`対象外` → 決まったラベルのどれか）
  - 区分のラベルが既に決まっているなら、説明でもそのラベルだけを使い、新しい語を足さない（足すなら、足すことを断ってから）
  - 動作の語（残す・消す）でなく、状態の語（使用中・不使用）でラベルを付ける
  - 否定形を残してよいのは、否定そのものが主張のとき（規範 8 と同じ考え方）
- 機械で拾えるか（ja-textlint の規則で「〜されていない」を見出し・表の中で候補に出せるか）は、足すときに試す
- skill を直したら、規定どおり整合のチェックを観点を変えて 3 周回し、`bin/skill-eval` も回す（`.claude/rules/skill-eval-after-edit.md`）
