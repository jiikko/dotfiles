# glogx: push アニメーションが timeNow() テストシームを迂回して time.Now() を直呼び

## 現状 (grep で確認済み, 2026-08-06)

`src/glogx/tui.go` には `var timeNow = time.Now` (「テストで固定するため差し替え可能にしている」と明記) があり、ファイル内の他の時刻取得はこれを経由している。しかし push アニメーション関連の 4 箇所 (`startPushAnim` / `advancePushAnim` 周辺: `pushAnimNext` の設定 ×3、`pushSlides` への記録 ×1) だけ `time.Now()` を直呼びしており、ファイル内規律と食い違っている。

## 提案

4 箇所を `timeNow()` に置き換える (ファイル内関数なのでシグネチャ変更不要)。

## 効果

push アニメーションの時間経過を他の箇所と同じパターンで固定時刻テストできるようになる。実時間待ちベースのテストは flaky かつ遅い。

## 注意

- 現状この 4 箇所を検証するテストが存在するかは未確認。存在しなければ「規律の一貫性回復 + 将来のテスト容易性」のみが効果 (実害は小さい)
- codex レビューはユーザー方針 (codex 不使用) により省略
