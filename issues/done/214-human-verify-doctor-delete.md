# 214 human: doctor の削除を実機で一度動かして確かめる

起票日: 2026-09-03
期限: 2026-09-10
関連: [issues/148](148-feat-glogx-doctor-disk-diagnosis.md) 段階 ④ / `src/doctor/disk/delete.go` /
`src/glogx/doctor_delete.go`

## なぜ人がやるのか

④ (削除) は 2026-09-03 に実装したが、**検証はすべて fake runner と偽 HOME の下のテスト**で、
実データを消したことが一度も無い。テストのハーネス (`disk/main_test.go`) は
「サンドボックス外を触ったら実行前に拒否する」形なので、**実データに対する挙動は構造的に
テストの外**にある。

特に次の 3 つは、実物でしか確かめられない:

1. **ゴミ箱への移動が Finder から見えるか**。`renameatx_np(RENAME_EXCL)` で `~/.Trash` へ
   移すが、Finder が「元に戻す」を出せるかは実物で見るしかない
   (`.DS_Store` / `com.apple.metadata` の扱いはこちらの管轄外)
2. **`cli:` 経路が本当に効くか**。`go clean -modcache` / `brew cleanup` /
   `xcrun simctl runtime delete <id>` は fake でしか叩いていない
3. **「未完了」の表示が実際に出るか**。`simctl` は非同期に消すので、削除の直後の再走査では
   まだ残っているはず = `🚨 未完了` が出るのが正しい

## 手順

1. `glogx` を開いて `D` (doctor)。スキャンの完了を待つ
2. **まず安全なものから**。`✅ 安全` の行 (例: `Go build キャッシュ` / `npm キャッシュ`) を
   `Space` で 1 件だけ選び、`d` → 確認の内容を読んでから `y`
   - [ ] 確認プロンプトに出た件数・サイズと、結果の「解放しました」が矛盾していないか
   - [ ] 閉じた後に自動で再スキャンが走り、その行が消える (or 小さくなる) か
3. **ゴミ箱の経路**。`⛔ 要確認` の行 (`Finder の .nsird 残骸` 等) を `Enter` で開いて中身を
   確認してから選ぶ (中身を見るまで選べない仕様)
   - [ ] Finder のゴミ箱にそれが入っているか。**「元に戻す」で戻せるか**
   - [ ] 結果の表示が「ゴミ箱へ移動」で、「解放しました」に**足されていない**か
4. **`cli:` の経路**。`Go module キャッシュ` か `シミュレータランタイム` を 1 件
   - [ ] `simctl` の場合、結果が `🚨 未完了` になり「時間をおいて再スキャン」と出るか
   - [ ] 時間をおいて `r` で再スキャンすると、実際に消えているか
5. **中断**。重いエントリ (DerivedData 等) を選んで `d` → `y` → 実行中に `Ctrl-C` を 2 回
   - [ ] 1 回目で落ちず、2 回目で中断できるか (**1 回で glogx ごと落ちたら報告**)
   - [ ] 中断後も glogx が生きていて、再スキャンできるか
6. **記録**。`ls ~/.cache/glog/doctor-history/` (または `$XDG_CACHE_HOME/glog/doctor-history/`)
   - [ ] 操作ごとに JSON が 1 本増えているか。`phase` が `done` か
   - [ ] 中断した回は `aborted`、途中で落ちた回は `executing` になっているか

## 報告してほしいこと

- 上のチェックで**食い違ったもの**(数字が合わない / 表示と実体が違う / ゴミ箱に無い)
- 削除に**時間がかかりすぎた**と感じたか (確認プロンプトが出るまで数秒かかる作りなので、
  体感が許容範囲かを知りたい。許容外なら `ScanTimeout` / 進捗の出し方を見直す)
- 画面の文言で**分かりにくかったもの**

## ⚠️ 注意

- **`~/Library/Caches` 配下や DerivedData は消えても再生成される**が、`⛔ 要確認` の行は
  ユーザーのファイルでありうる。ゴミ箱へ移動する作りなので戻せるが、**空にする前に**確認すること
- 何かおかしいと思ったら `Ctrl-C` を 2 回。記録は `doctor-history/` に残る
