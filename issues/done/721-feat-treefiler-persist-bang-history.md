# 721 (feat): treefiler の `!` のコマンドの履歴を、閉じても残す

起票日: 2026-10-12

## 概要

`!` の入力欄は ↑ / ↓ で前に打ったコマンドを呼び戻せる (`src/treefiler/filer/shell.go` の `promptState.history`)。ただし履歴は Model の中だけにあり、**プロセスを終える (glogx・`bin/treefiler` を終了する) か、別の dir で `F` を開く (Model を作り直す) と消える**。
同じ dir で `F` を閉じて開き直すだけなら、glogx は Model を使い回す (`src/glogx/filer_view.go` の `toggle`) ので今でも残る。プロセスと dir をまたいで残るようにする (ユーザーの選択 2026-10-12。依頼は「! の履歴」で、起票時に既に Model の中の履歴はあると分かったので、残す方を issue にした)。

## 仕様 (案)

- 履歴をファイルに保存し、Model を作るとき (`filer.New`) に読む。保存先は設定と同じ dir (`configDir()`: `TREEFILER_CONFIG_DIR` → `~/.config/glogx`)。
  名前は `treefiler-history` (`treefiler-places` / `treefiler.toml` と並べる)
- **保存の契機は「打つたびに 1 行追記」** (`promptKey` の Enter で履歴へ足すところ)。閉じるとき (`Close`) にまとめて書く形にしない:
  `Close` は F を閉じる・他の画面へ移るたびに呼ばれ、逆にシグナル・panic で落ちたときは呼ばれない (`bin/treefiler` は `filer.Quit` のときだけ呼ぶ)
- **2 つの treefiler が同時に開いているとき (glogx を 2 つ) も失わない**: 追記は `O_APPEND` で 1 行ずつ書く (zsh の `INC_APPEND_HISTORY` と同じ考え方)。
  places.go の「読む → 足す → 全体を書く」(後勝ちの全置換) は、履歴では先に閉じた方の分を全部消すので使わない。開いている間に他方が足した分は、
  次に Model を作るときに読まれる (開いている Model 同士で同期はしない)
- 件数の上限 200 件 (今のメモリ上の履歴には上限が無い。新しい仕様)。読むときに末尾 200 件だけを取る。ファイルが上限の 2 倍を超えていたら、読んだ直後に
  末尾 200 件で書き直す (`atomicfile.Write`。places.go と同じ)。同じコマンドが続いたら 1 件にする (今の挙動と同じ。離れた重複は残す)
- 1 行の形式: コマンドを `strconv.Quote` した 1 行 (改行や制御文字を含むコマンドでも 1 行に収め、読むときに `strconv.Unquote` で戻す。戻せない行は捨てる)
- 先頭が空白のコマンドは保存しない (zsh の `HIST_IGNORE_SPACE` と同じ。秘密を含むコマンドを残さない逃げ道。メモリ上の履歴には今どおり残す)
- 🚨 履歴にはコマンドの中身 (パス・引数) がそのまま残るので、ファイルの権限は 0600 (作るときの `OpenFile` の mode と、書き直しの `atomicfile.Write` の mode の両方)
- 単体の `bin/treefiler` と glogx の `F` で同じ履歴を使う。範囲は `!` だけ (`/` の検索の「前回の検索」は 1 件だけの `m.lastSearch` で、今回は残さない)

## 対応方針

- 履歴の読み書きは UI と分けた小さな関数 (読む / 1 行足す / 切り詰める) にし、そこにテストを集める
- 読み込みは壊れたファイル・巨大なファイル・長い行で落ちない。`bufio.Scanner` の 1 行 64KiB の上限を超える行は捨てて読み進める
  (places.go の `readPlaces` は読み切れないと書き戻さない構えだが、履歴は 1 行ずつ独立なので捨てて続ける)
- 書き込みの失敗 (dir が無い・権限) はコマンドの実行を止めない (toast も出さない。履歴は付け足しの機能)

## 受け入れ条件

- [x] 2 つの Model が交互に打った履歴が両方残る / 上限で切り詰められる / 先頭が空白のコマンドは保存されない / ファイルの権限が 0600
- [x] 壊れた履歴ファイルで落ちない
