## 残課題 (すべて切り出し済み)

1. **fixture が「2 つの数字を取り違える変異」を検出できなかった**
   (glogx 側の fake で docker 申告と候補の見積もりを同じ値にしていた)。
   → ✅ `mutation-verify-new-tests.md` の「よくある『守っていないテスト』の形」へ追記
   (「取り違えを検出したい 2 つの値を、fixture で同じ値にしていないか」)。実例は rationale へ
2. **観測できない死んだ防御を 1 つ書いた** (時計巻き戻しのクランプ)。
   → ✅ **切り出さない**。`verify-execution-not-just-exit-code.md` の「有無で結果が変わらない
   観測を証拠に数えない」が既に一般則を持っており、今回はそれが**防御側**に出ただけで
   発動点は同じ (「その機構を外したら結果は変わるか」)
3. **`doctor/docker` は無害化の網羅検査 (`display_coverage_test.go`) を持たない**。
   → ✅ issue 252 へ追記済み (svc と docker の 2 つが待っている。3 実装を持たないため共有ヘルパー待ち)
4. **`disk.HumanSize` は 1024 進、`docker.HumanSize` は 1000 進**で、タブ行に 2 つの単位系が並ぶ。
   → ✅ **揃えないと決めた**。docker の数字を 1024 進で丸め直すと `docker system df` と
   突き合わせられなくなる (画面の数字を疑ったときに確かめる手段が消える)。**見た目の統一より
   外部ツールとの照合可能性を優先**する。理由は `src/doctor/docker/size.go` の `HumanSize` に
   コメントで残した (次の audit が同じ指摘を再生成しないため)。揃えるなら「両方を併記」の方向
5. **`--help` の文面を根拠に破壊的操作の範囲を決めて誤った** (`docker builder prune` の `-a`)。
   敵対レビューの指摘を却下し、その理由をコードに書くところまで進んでいた。実行時の警告文が正本。
   → ✅ `measure-external-cli-streams-separately.md` へ追記
   (「`--help` を、破壊的操作の範囲の根拠にしない」)。実例は rationale へ
6. **非対話で走らせる CLI がプロンプトで空振りし、rc=0 + それらしい stdout を返した**
   (`docker ... prune` に `-f` が無い状態)。確認画面で `y` を押しても 1 バイトも減らない配線だった。
   → ✅ `verify-execution-not-just-exit-code.md` へ節を追記
   (「確認を求める外部コマンドは、非対話だと『何もせず rc=0』で返る」)。実例は rationale へ
7. **提示コマンドを部分一致で pin していたので、`-f` / `-a` の増減を検出できなかった**。
   → ✅ 1 と同じ節へ追記 (「文字列を部分一致で pin していないか」)
8. **コードのコメントの誤りが、敵対レビューを誤検知へ誘導した** (上記 P1-1)。
   → ✅ **切り出さない**。「実装で強制できない事実はコメントに書く / 実測で裏を取る」は
   `comment-no-restate-enforced.md` と `measure-external-cli-streams-separately.md` が
   すでに持っている。今回は**外部 CLI の挙動を実測せずにコメントへ書いた**のが原因で、
   後者の「`--help` を根拠にしない」節 (項目 5 で追記) が同じ発動点をカバーする
