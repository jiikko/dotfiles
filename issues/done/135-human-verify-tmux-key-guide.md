## 確認してほしいこと

1. **prefix 押下中だけ右端にガイドが出るか**: `prefix`（C-t）を押したまま止めると
   status バーの右端に ` m:予約 g:glogx ?:キー一覧 ` が緑で出て、キーを離すと消えること。
2. **window list がガタつかないか**: prefix の押下・解放で window 一覧の描画位置・幅が
   動かないこと（両分岐を 27 セル固定にした狙いはこれ。動くなら幅の固定が破れている）。
   ⚠️ 右端に 27 セルを常時予約するので、**端末が狭いと window 一覧が切れる**かもしれない。
   切れるなら文言を詰める（`?:一覧` にすると 23 セル、`g:git` にすると 25 セル）。
3. **緑が読めるか**: 左端の `⚡ PREFIX ARMED ⚡` と喧嘩していないか。うるさければ
   `@keyguide` の文言か色（`_tmux.conf` の status-right ブロック）を調整する。
4. **`prefix + ?` が使えるチートシートになっているか**: 一覧に予約入力・glogx・
   エージェントパネル等の自作キーが日本語の注記つきで出ること。
   注記の文言が分かりにくいものがあれば、その `bind -N` を直す（注記が唯一の出典）。
5. **文言が想起に足りるか**: `m:予約` / `g:glogx` だけで思い出せるか。他に常時出したいキーが
   あれば足せる（伸ばすときは `#{pN:}` の 2 箇所と `status-right-length` を同じ値に揃える。
   幅は数えずに tmux に測らせること）。
