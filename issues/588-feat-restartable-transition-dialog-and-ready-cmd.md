# 588 (feat): restartable — 再起動中・終了中に画面の真ん中へ板を出し、--ready-cmd でアプリの起動完了まで出し続ける

> 🚨 **担当中: SFTP issue checkpoint [59ecdd]**（2026-10-01〜）

起票日: 2026-10-01

## 概要

[586](done/586-feat-restartable-foreground-restart-runner.md) の restartable を obaket の `make dev-fg-loop` で使ったユーザーの依頼 (2026-10-01):

> restartしてアプリが起動するまではstdoutの真ん中に再起動中のダイアログを表示することできますか？ それとquitをして終了中も同じようにダイアログを表示してほしい

ユーザーの選択: 案 A (inline のまま表示の領域を広げ、板を画面の縦の真ん中に置く。ログは板の上の領域で流れ続け、スクロールバックにも残る) と `--ready-cmd`。
合意した見本 (80 桁):

```
tick 41
tick 42
          ┌─ 再起動中 ─────────────────────────┐
          │ ⠋ アプリを終了しています…           │
          │   終了 → ビルド → 起動              │
          │                                     │
          │ Esc: 取り消し   Ctrl-C: 強制終了    │
          └─────────────────────────────────────┘



── [R] 再起動  [Q] 終了 ─────────────────────────────────────── stopping
```

## 要件

- T1 再起動 (R の確定 / control の restart) の間、板「再起動中」を出す。段 (終了 → ビルド → 起動) と今の段を示し、今の段の行に動く印 (spinner) を出す。
  板は「起動の確認」(T3) が済むまで出し続ける。ビルドに失敗したら板に「ビルドに失敗した」と出して閉じ、最下行は build-failed
- T2 終了 (Q の確定) の間、板「終了中」を出す (「アプリを終了しています… Esc: 取り消し / Ctrl-C: 強制終了」)。子が終わるまで出し続ける。Esc で取り消したら閉じる
- T3 `--ready-cmd <cmd>`: 子を起動した後、cmd を `/bin/sh -c` で繰り返し実行し (間隔 0.5 秒、1 回の上限 5 秒)、rc 0 で「起動の確認」が済む。
  `--ready-timeout` (既定 120 秒) を過ぎたら板に「起動を確認できなかった」と出して閉じる (子は殺さない)。子が先に終わったら確認をやめる。
  cmd には `--id-env` の識別子を渡す。`--ready-cmd` が無いときは、子を起動した時点で確認が済んだとみなす (今の挙動)
- T4 最初の起動でも、ビルドから起動の確認までは同じ板 (見出しは「起動中」) を出す
- T5 板の置き場所: 案 A。View は「板 + 空行 + 最下行」にして、**板より上は View に含めない** (そこはログの領域で、ログが流れ続けて見える)。板の上端が
  縦の真ん中付近に来るよう、板と最下行の間の空行で高さを決める。横は真ん中。端末が小さくて入らないときは最下行の直上に詰める。
  板の案内は段に合わせる (Esc は終了の待ちの段だけ、Q は受け付ける段だけ)。段の行は済んだ段に ✓ を付ける
- T6 板を出している間のキー: Ctrl-C は強制終了 (今のまま)、終了の待ち (stop-cmd 成功後) は Esc で取り消し (今のまま)。R は無視して板に「処理中」と出す。
  Q はビルドの段と起動の確認の段では受け付け (確認ダイアログ → y で終了中の板へ。ビルド中は今までどおりビルドを止めて終わる)、終了の段では無視する
  (2026-10-01 改訂: 最初の版は R / Q を両方無視にしていて、--ready-cmd が成功しないと最大 120 秒 Q で穏やかに終われなかった)
- T7 status の JSON に、起動の確認がまだか (`ready: false`) を足す (dev-restart などが使えるように。既存の欄は変えない)
- T8 端末でないとき (非 TTY) は板を出さない。起動の確認が済んだこと / できなかったことは 1 行ずつ stderr に出す
