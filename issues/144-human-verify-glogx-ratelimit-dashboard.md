# glogx の全画面 ratelimit ダッシュボード (R) を目で確認する

期限: 2026-09-04

## 背景

`R` で開く全画面ダッシュボードを追加した (e0fe0ea まで)。枠 (Claude 5h / Claude weekly /
codex 5h / codex weekly) ごとに 1 枚のアナログ盤を 2x2 で並べる。

**色と間隔は幅テストでは判定できない** (どちらも「桁は合っているが目には合っていない」形で
壊れる。`_claude/rules/no-mixed-width-columns-in-terminal-ui.md` と同じ理由)。実端末で見る
必要がある。

## 確認手順

```
glogx        # git log 一覧で R を押す
# 色だけ先に見るなら本体を起動せずに:
cd src/glogx && go run ./tools/dial-preview -w 120 -h 44
```

## 見てほしいところ

- [ ] **色が判別できるか**。緑 (適正) と青 (余裕・使い残し) を Cyan → BrightBlue に変えた。
      盤に乗る色は「時間 = BrightWhite (外周の残り弧と針) / 消費 = 状態色」の 2 系統だけ。
      まだ似て見えるものがあれば、どれとどれかを書く
- [ ] **間隔**。段と段のあいだの空行 1 行 / カード間 4 桁 / 盤とゲージのあいだ 1 行。
      足りない・空きすぎがあれば書く
- [ ] **ゲージの背景色** (`[ 1 2 3 4 5 ]`)。緑背景 = 想定内 / 赤背景 = 前借り /
      青 = 使い残し / 暗灰 = 未来 / 下線 = いま居るスロット。statusline のペース行と
      同じ見え方になっているか (2 か所で同じ意味の色が違うと読み替えが要る)
- [ ] **盤が円に見えるか**。braille のドットを正方形と仮定している。フォントによっては
      縦長・横長に見えるかもしれない
- [ ] **端末を縮めたときの落ち方**。幅を狭めると 2 カラム → 1 カラム → テキストカード、
      高さを縮めると予算と助言 → ゲージ の順に消える。読めなくなる形がないか
- [ ] **1 分ごとに更新されるか**。開いたまま放置して針と残り時間が動くこと

## 気になっている点 (未検証)

- 針と外周の残り弧が同じ色 (BrightWhite) なので、盤が明るすぎるかもしれない
- 目盛り (窓の等分) が細かい点の集まりに見えて、ノイズと区別しづらいかもしれない

### 却下・記録 (対応しない理由)

- **`putText` が結合文字を捨てる / CSI パラメータを素通しする**: `putText` に外部文字列が
  流れる経路は versionTag だけで、そこは無害化済み。到達不能。外部文字列を新たに盤へ
  載せるなら再評価する
- **`padTo(page < 0)` で panic**: `pageSize()` が `max(..., 1)` なので呼び出し元から負に
  なれない。glogx 全体の viewer が同じ前提に乗っている
- **`renderWindows` が枠を重複させうる**: codex 枠のラベルが `"5h"` だと 2 枚になるが、
  `codexLabel` が必ず `cx` を前置するので実データでは起きない。`render.go` は今回の
  変更対象外
- **格子の最後の砦 (`termwidth.Truncate`) を外しても全緑**: 現状は本当に冗長で単一障害点
  ではない (26..200 x 6..60 で cell 行は cellW を超えない)。将来「冗長だから外す」判断が
  入ったときのために残す
- **`bannerWidth` が `termwidth.Of` を介さない**: 字形表が閉じた ASCII 集合なので桁数 =
  字数 x 字幅 で決まる。実描画幅との一致はテストが固定。コード側にコメントを残した
- **`handleKey` の `left` がヘルプ未記載**: `diff_overlay.go` / `status_view.go` 等と同じ
  既存パターン (`h`/`left` を対で持ちヘルプには `h` だけ書く)。この機能固有の乖離ではない
- **クリアランステストは `drawCenter` を丸ごと落とす変異では空回りする**: 中央が描かれる
  ことは `TestRenderDashboardCenterShowsRemainAndPercent` /
  `TestRenderDashboardCenterAAShowsActualPercent` が別に守っている
