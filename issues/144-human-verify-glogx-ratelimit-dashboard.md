# glogx の全画面 ratelimit ダッシュボード (R) を目で確認する

期限: 2026-09-04

## 背景

`R` で開く全画面ダッシュボードを追加した (e0fe0ea まで)。枠 (Claude 5h / Claude weekly /
codex 5h / codex weekly) ごとに 1 枚のアナログ盤を 2x2 で並べる。

**色と間隔は幅テストでは判定できない** (どちらも「桁は合っているが目には合っていない」形で
壊れる。`_claude/rules/no-mixed-width-columns-in-terminal-ui.md` と同じ理由)。実端末で見る
必要がある。

## 確認手順

```
glogx        # git log 一覧で R を押す
# 色だけ先に見るなら本体を起動せずに:
cd src/glogx && go run ./tools/dial-preview -w 120 -h 44
```

## 見てほしいところ

- [ ] **色が判別できるか**。緑 (適正) と青 (余裕・使い残し) を Cyan → BrightBlue に変えた。
      盤に乗る色は「時間 = BrightWhite (外周の残り弧と針) / 消費 = 状態色」の 2 系統だけ。
      まだ似て見えるものがあれば、どれとどれかを書く
- [ ] **間隔**。段と段のあいだの空行 1 行 / カード間 4 桁 / 盤とゲージのあいだ 1 行。
      足りない・空きすぎがあれば書く
- [ ] **ゲージの背景色** (`[ 1 2 3 4 5 ]`)。緑背景 = 想定内 / 赤背景 = 前借り /
      青 = 使い残し / 暗灰 = 未来 / 下線 = いま居るスロット。statusline のペース行と
      同じ見え方になっているか (2 か所で同じ意味の色が違うと読み替えが要る)
- [ ] **盤が円に見えるか**。braille のドットを正方形と仮定している。フォントによっては
      縦長・横長に見えるかもしれない
- [ ] **端末を縮めたときの落ち方**。幅を狭めると 2 カラム → 1 カラム → テキストカード、
      高さを縮めると予算と助言 → ゲージ の順に消える。読めなくなる形がないか
- [ ] **1 分ごとに更新されるか**。開いたまま放置して針と残り時間が動くこと

## 気になっている点 (未検証)

- 針と外周の残り弧が同じ色 (BrightWhite) なので、盤が明るすぎるかもしれない
- 目盛り (窓の等分) が細かい点の集まりに見えて、ノイズと区別しづらいかもしれない
