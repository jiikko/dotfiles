# 434 (retro): pro-con の daemon を本物の claude につないだ夜 (427 の段階 3)

起票日: 2026-09-25

## 概要

427 の段階 3 (daemon・PM への指示書・本物の claude での通し) を、敵対的レビュー 10 周と本物の claude での通し 2 回で閉じた。
うまくいった話は書かない。回りくどかった所と、他の作業にも効く形の改善だけ。

## どこで踏んだか

1. **fake の前提が本物と違ったまま、机上の周回を 5 周重ねた**。fake の `Resume` は「同じ session を続ける」前提で書いていたが、
   本物の `claude --bg --resume` は別の session id の session を立てる (3f で実測)。5 周のあいだの指摘と修正の一部は、
   この前提の上に建っていた (再開の取り込みを前の session id で探す等、本物では決して一致しない分岐)。
   「本物の挙動は未実測 (3f で測る)」という指摘は 1 周目から出ていて、周を追うごとに増えていたのに、実機を挟んだのは 5 周目の後だった
2. **同じ判定 (PG の session が生きているか) を 3 か所に別々に書き、周回の指摘の多くがその食い違いから出た**
   (pid 0 を一覧に無いと読むか / 記録の pid と違うと読むか / 待ちの起点をどの時刻にするか。7〜10 周目)。
   1 か所に寄せていれば、同じ形の指摘は 1 回で済んだ

## 次に効きそうな改善 (切り出し先の提案。実行はユーザーの判断を待つ)

1. **自分が書く fake の前提も「仮説」に数える**。外部 CLI の状態遷移 (再開・再起動・停止で id / pid / 時刻がどう変わるか) を
   模した fake は、書く前に 1 回実測する
   → 切り出し先: `_claude/rules/measure-external-cli-streams-separately.md` の既存の項「外部ソース (upstream のソース・ドキュメント・要約) は
   仮説であって実測ではない」を広げる (新しい項は立てない。外部ソースだけでなく、それを読んで自分が書いた fake の振る舞いも同じ扱い)
2. **§7 の「実機を 1 回挟む」の発動の時点を具体にする**。今の文言は「観測 API が絡むなら、周回を増やす前に」で、いつ挟むかが読み手の判断に
   委ねられていた (今回は 1 周目から条件を満たしていたのに 5 周目の後になった)。「周回の指摘に『本物の挙動が未実測』が 1 つでも出たら、次の周の前に」
   → 切り出し先: `_claude/rules/adversarial-review-own-safeguards.md` §7 の該当の項へ 1 行追記
3. 周回の指摘が、同じ判定の**別の書き方の食い違い**から続けて出たら、次の修正を当てる前にその判定を 1 つの関数へ寄せる
   → 切り出し先: `_claude/rules/adversarial-review-own-safeguards.md` §7 へ追記 (発動点は §7 の「周回を続ける」判断そのもの)

反証レビュー (sonnet、読み取りのみ) で直した点: 「3 周目の時点で分かっていた」を 427 の記録に合わせて「1 周目から」に訂正 /
提案 1 は既存の項と重なるので新規の追記ではなく既存の項を広げる形に / 提案 2 は §7 の既存の文言との差 (発動の時点) だけに絞った。
