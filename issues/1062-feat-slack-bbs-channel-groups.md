# 1062 (feat): slack-bbs で複数のチャンネルを 1 つのグループとして購読し、話題に組み直して読む

起票日: 2026-11-11

## 概要

指定した複数のチャンネル (個人の分報のチャンネルをまとめたもの等) を、論理的な 1 つのチャンネルとして購読する。
グループの中の発言はまとめて話題に組み直して読む (ユーザー要望 2026-11-11)。

## 背景

- 706 の MVP は「チャンネルをまたいだ話題の統合」を作らないものに入れ、「複数チャンネルの横断」を未決の論点に残した
  (706 の「MVP (slack-bbs)」と「未決の論点」)。この issue はその論点を、ユーザーが選んだチャンネルの組に限って開く
- 今は購読の単位がチャンネル 1 つで、読む画面のタブ・取得・分類・キャッシュ・既読の印がどれもチャンネルの ID を鍵にしている

## 今の作りでチャンネル 1 つを前提にしている所 (2026-11-11 に読んだ)

- `subs.Channel` (ID と名前) の並びがタブになる (`src/slack-bbs/subs/store.go`)
- `render.Page` は `Channel` を 1 つだけ持ち、Slack のリンク (`Page.URL`) をその ID で組む。グループの話題では、単位ごとに元のチャンネルが要る
- 単位の ID はスレッドの ts で、ts はチャンネルの中でしか一意でない。グループの中では、単位の ID・既読の印 (`Reads`)・
  キャッシュの鍵 (`cache.Store` の `ch`) にチャンネルを含める必要がある
- 分類 (`claude -p`) は 1 チャンネル分の発言を 1 回で渡す。グループでは渡す量が足し算で増える (706 の「量が多いとき」)

## 対応方針 (案)

- 購読の一覧にグループを足す: 名前と、属するチャンネルの ID の並び。タブにはグループが 1 つとして並ぶ
- 取得はチャンネルごとに行い、発言にチャンネルを付けてから 1 つの板に合わせて分類する。本文の発言の頭にチャンネル名を出す
- 購読の画面 (`s`) でグループを作る・チャンネルを出し入れする

## ユーザーに決めてもらうこと

- グループの決め方: 自分でチャンネルを選んで組むか、名前の頭が同じチャンネル (個人の分報など) を自動でまとめるか
  (自動なら、新しく作られたチャンネルも次の読み直しで入る)
- 話題の組み直し: グループの中でチャンネルをまたいで 1 つの話題にまとめるか、チャンネルごとに話題を組んで 1 つのタブに並べるだけにするか
