# 157 human: ratelimit ダッシュボードの盤 (円周の背景帯) を実端末で見て可否を決める

起票日: 2026-09-02
期限: 2026-09-05

対象コミット: `ffc9d5f` (feat(glogx): ratelimit ダッシュボードの円周を背景色の帯にする)

## お願いしたいこと

実端末で次を実行して、**採用のままでよいか / 直したいか**を判断してください。

```
cd ~/dotfiles/src/glogx && go run ./tools/dial-preview -w 120 -h 36
```

glogx 本体からは `R` (全画面 ratelimit ダッシュボード)。プレビューは本体と同じ
`usage.RenderDashboard` を呼ぶので、見えたものがそのまま本体の見た目です。

## 入れた変更 (何を見るか)

1. **盤の内側**を 235 (一段浮かせた地。tmux バー地と同段) で塗り、盤を「面」にした
2. **外周を背景色の帯**にした。過ぎたぶん = 沈んだ灰 / 残り時間 = 明るい帯 (縮んで 0 = 復活)
3. 内周 (消費) は今までどおり前景の弧のまま = 状態色はここだけ

見てほしい点:

- 明るい帯 (残り時間) が**眩しすぎないか**。白 (`\x1b[47m`) を使っているので、端末の
  プロファイル次第では強すぎる可能性がある。落とすなら候補は 47 → 100 系や 256 色の中間調
- 盤の地 235 が、glogx の**最外周フレーム・カーソル行の地と喧嘩していないか**
- 帯の中に入った目盛り・12 時マーク・針の先端が**読めなくなっていないか**
  (白帯の上の白い前景は原理的に見えない。設計上は帯自体が同じ情報を持つので許容としたが、
  実際に見ると気になるかもしれない)
- 段が 2 つ (Claude / codex) 並んだとき、**地の面が増えて画面がうるさくないか**

## 選ばなかった案 (作り直すならここから)

`tools/dial-preview` で 5 案を出して 4 番を採用した。他の案は削除済みなので、戻すなら再実装:

| 案 | 内容 | 却下理由 |
|---|---|---|
| 1 | 外周だけ帯 (盤の地は塗らない) | 帯が浮いて「円」に見えない |
| 2 | 内周だけ帯 (消費を状態色の背景で) | 時間と消費のうち、太くしたいのは時間側だった |
| 3 | 盤の地だけ (円周は前景の弧のまま) | 「円周を太く」という元の要望を満たさない |
| **4** | **地 + 外周の帯 (採用)** | — |
| 5 | 外周・内周とも帯 | リング間隔 (4 ドット = 端末 1 行) では 12 時/6 時で同じセルに乗る。
間隔を 8 ドットに広げると内周が縮み、中央の大きい数字 (AA) が入らない盤が出る |
