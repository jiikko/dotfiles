## 要件 (確定)

### A. 木 = treebeard の見た目 (2026-10-07 に README・`src/ui.rs`・デモ動画のフレームで確認)

- **横に育つ木**: 左から右へ育ち、開いたフォルダは新しい列として右へ扇状に開く。**開いたフォルダは複数同時に開いたまま**
  横に並び、肘形の connector で結ばれる (旧未決 8 はこれで決まり: 1 本の木の展開でも yazi 型の切り替えでもなく、列が増える形)
- **固定の選択線**: root からカーソルまでが、画面の中ほどを通る 1 本の水平線になる。上下に動くと**列の方がスクロール**し、選択線は動かない。
  カーソル行は背景つきの pill で示す
- **線の描き方**: 既定は二重線の「管」(`═` `╔` 系) で継ぎ目を正しく描く。カーソルの経路は白、経路から外れた枝は薄く、
  他の枝はその枝の元のフォルダの熱の色で塗る。動くたびに光が線を伝ってカーソルへ走る。閉じたフォルダの後ろに `›` の芽
- **熱の色 (再帰的な mtime)**: ファイルは更新時刻、フォルダは**配下で一番新しい更新**で色を決める (log 時間の連続階調。既定 ember:
  分 = 赤 → 時間 = 橙 → 日 = 金 → 週 = 藤 → 年 = 灰青 → 5 年以上 = 青)。走査は裏で行い、上限 (5 万件) に当たったら末尾に `~`
- **ライブ更新**: 開いているフォルダはディスクの変化を約 1 秒で反映し、変わった項目が光り、その光が connector を伝って上の階層へ昇る
- **git**: 変更のあるファイルの名前の後ろに 1 文字の印 (`M` 黄 / `+` 緑 / `?` 水色 / `!` 桃)。閉じたフォルダの `›` は配下の最も緊急な変更の色。
  ignore されたものは灰色に沈める
- **動き**: すべての項目が臨界減衰のばねで動く (フォルダの展開・畳み込み、兄弟が脇へ滑る、connector が毎フレーム引き直される)。
  動いている間だけ描き、止まったら描かない
- **最下行のステータスバー**: 左にパンくず (`… › 名前`)、右に `⎇ ブランチ`・git の状態・ソート・件数とサイズ・熱の色の点と経過時間 (`● 6d ago`)・
  キーの案内 (`! cmd` `s shell` `q quit` `? keys`)。凡例 (熱の色の早見) も出せる

### B. プレビュー = ドラクエの対戦画面のタイル (treebeard から唯一変える所)

- ファイルで `→` / `Enter` を押すと、木の上にウィンドウタイルが開く。中身は**テキストのプレビュー**
- タイルの中からさらにファイルへジャンプすると、**今のタイルを閉じずに、新しいタイルを手前に重ねる** (ドラクエの対戦で
  コマンド → じゅもん → 対象と選ぶたびに窓が上に重なっていく形。旧未決 2 は「手前に重ねる」で決まり)。閉じると 1 枚ずつ下のタイルへ戻る
- タイルの中身の機能は treebeard のプレビューから写す: タイトル (`名前 · サイズ`)・右下の位置表示 (`d diff · 1/13`)・右端のスクロールバー・
  markdown の整形 (treebeard は `glow`) とコードの色付け (treebeard は `bat`)・`d` で git の diff と本体を切り替え・`j` `k` `Space` `Ctrl-D` `Ctrl-U` `g` `G` のスクロール
- 枠・ずらし幅・重なりの奥の見せ方 (暗くするか) はサンプルで決める

### C. treebeard のその他の UI (依頼に無いが写す。キーは treebeard の README の表)

- 移動: `j` `k` (開いている木全体を読む順に) / `↓` `↑` (列の中をまっすぐ) / `J` `K` (木全体を読む順に 10 件) / `PgDn` `PgUp` (列の中を 10 件。
  README の表は `J` `K` と同じ行に並べるが、実コードは別の動き。`main.rs` のキー分岐) / `g` `G` `Home` `End` / `l` `→` `Enter` (開く) / `h` `←` (親へ)
- 畳む: `Space` `Tab` (開閉) / `c` (カーソル下を畳む) / `C` (カーソルの経路以外を全部畳む) / `e` (explode: 配下を全部開く。400 フォルダか 6000 件で止める。`Esc` で中断)
- 探す: `/` (今の列の中であいまい検索。入力中は `Tab` `↓` / `⇧Tab` `↑` で一致を移り、空欄の `↑` で前回の検索を呼び出し、`Enter` で留まり、`Esc` で元の位置へ戻る) /
  `n` `N` (次・前の一致)
- 終了: `q` (終了。`--cwd-file` 付きで起動したときだけ shell をそこへ cd させる) / `Esc` `Ctrl-C` (終了。cd しない)
- 起点: **glogx の pwd (カレントディレクトリ) を root にして始める** (2026-10-07 ユーザー回答。treebeard は「対象の親」を root にするが、そこは写さない)。
  `-` `Backspace` で 1 段上へ root を付け替える
- 表示: `.` (dotfiles の表示切替。既定は隠す) / `r` (再読込)
- **ソートは後回し** (2026-10-07 ユーザー回答「後から考える」)。最初は名前順だけで、treebeard の巡回 (名前 → 新しい順 → 大きい順 → 種類)・逆順・
  ステータスバーのソート表示・設定の Sort by / Reverse は入れない。キーも決めない
- 外で開く: `o` (glogx の語彙のまま。treebeard には無い)
- シェル: `!` (選んだフォルダでコマンドを 1 行実行。`$f` が選んだパス。入力中は `↑` `↓` で履歴、`Ctrl-U` `Ctrl-W` で消す、`Esc` で取り消し。
  3 秒未満で終わったコマンドは出力を読めるようキーを待つ) / `s` (そこでシェルを開く)
- 設定: `,` (右側に設定の板。中は `j` `k` で移動、`h` `l` `←` `→` `Enter` `Space` で値を変え、`r` で既定へ戻し、`Esc` `,` で閉じる。
  treebeard は 35 項目を `~/.config/tb/config.toml` に保存するが、**こちらは `~/.config/glogx/` の下に置く** (2026-10-07 ユーザー回答)) / `?` (キーの一覧の板)
- **マウスは写さない** (2026-10-07 ユーザー回答「マウスは映さない」)。treebeard のクリック・ホイール・慣性と、設定の Mouse / Wheel speed / Momentum の項目も外す
- プレビューの中のキー: テキストは `q` `Esc` `h` `←` で閉じる。画像・PDF は `j` `k` `Space` でページをめくり、`↑` `↓` で同じフォルダの前後の画像へ、`i` でピクセルとブロックを切り替える
- 画像・PDF のプレビュー。**文字のブロックで描く** (2026-10-07 ユーザー回答)。kitty / sixel / iTerm2 のピクセル描画と、`i` (ピクセルとブロックの切替)・
  設定の Image previews は写さない。ブロックの形 (treebeard の設定 Block glyphs: half / quadrants / sextants。既定は quadrants) は写す
- **音声は再生しない** (2026-10-07 ユーザー回答「音声は再生しなくていい」)。treebeard の音声プレイヤー (波形・シーク・音量のキー) は写さない。
  音声ファイルは開けず、表示できない旨を toast で出す (未決 8)
- 前回の場所を覚えて再開する (設定で on)
