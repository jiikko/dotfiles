## 残課題 (切り出し先の提案つき)

1. **fixture が「2 つの数字を取り違える変異」を検出できなかった**
   (glogx 側の fake で docker 申告と候補の見積もりを同じ値にしていた)。
   変異 P4 が緑で、fixture を直して初めて red になった。
   → **`mutation-verify-new-tests.md` の「よくある『守っていないテスト』の形」に追記**:
   「**取り違えを検出したい 2 つの値を、fixture で同じ値にしていないか**」。
   既存の「期待値を production と同じ式から作る (自己言及)」の隣に置ける形なので、
   新規ルールは立てない
2. **観測できない死んだ防御を 1 つ書いた** (時計巻き戻しのクランプ)。変異しても緑のままで、
   丸めても丸めなくても `age < OldAfter` で候補から外れるので何も変わらなかった。
   削除してその旨をコメントに残した。
   → **切り出し不要** (`verify-execution-not-just-exit-code.md` の「有無で結果が変わらない
   観測を証拠に数えない」が既にこの形の一般則を持っている。今回はそれが**防御側**に出ただけで、
   発動点は同じ「その機構を外したら結果は変わるか」)
3. **`doctor/docker` は無害化の網羅検査 (`display_coverage_test.go`) を持たない**。
   → **issue 252 に追記済み** (svc と docker の 2 つが待っている状態。3 実装を持たないため
   共有ヘルパー待ち)
4. **`disk.HumanSize` は 1024 進、`docker.HumanSize` は 1000 進**で、同じ doctor 画面に
   2 つの GB 表記が並ぶ。docker の数字を 1024 進で丸め直すと `docker system df` と
   突き合わせられなくなるので今の形にした。
   → **人の判断待ち** (画面で並べて気になるかどうか)。気にならなければこの項は却下でよい
