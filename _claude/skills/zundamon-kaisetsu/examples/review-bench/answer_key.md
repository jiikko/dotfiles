# 試験用の台本 (script.json) に仕込んだ欠陥

`script.json` は、台本の校正 (`zundamon-kaisetsu lint`) と、手順 3-3 の確認役 (サブエージェント) を試すための合成の台本。
行番号は `lines` の添字 (0 始まり)。題材は一般的な話 (パスワードの使い回し) で、特定の資料には依らない。

| 行 | 欠陥 | lint の規則 |
|---|---|---|
| 3 | ずんだもんの「のだ」が 1 行に 2 回 | `noda` (警告) |
| 4 | チャプターが変わっても前の図解 (重要語) が出たまま | `show-across-chapter` (警告) |
| 5〜7 | めたんが 3 行続く | `metan-run` (目安。rc に効かない) |
| 6 | 漢数字 (四つ) | `kanji-number` (目安。rc に効かない) |
| 7 | 字幕が 60 字を超える | `long` (警告) |
| 9 | 「この図を見て」で図解を指す | `pointing` (警告) |
| 10 | ずんだもんの一人称が「わたくし」 | `pronoun` (警告) |

- lint は上の 7 個をすべて出し、ほかは出さない (`src/zundamon-kaisetsu/lint_test.go` が固定する)
- 確認役の試験 (issue 677) では、lint が拾う分を除いた欠陥 (事実の誤り・図解とセリフの食い違い・読み) を、この台本に足して使う
