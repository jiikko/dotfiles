# mac-healthcheck の助言と寿命の判断の基準

SKILL.md の手順 4 (寿命) と手順 5 (よく使うソフトへの助言) が読む。数値の閾値の正本は `src/doctor/health/` の定数で、ここには判断の組み立て方だけを書く。

## 寿命: このまま使える / メンテナンスを勧める / 買い替えを検討する

上から順に当てはめ、最初に当たったものにする。どれも根拠の項目 (ID と値) を添える。

| 結論 | 当たる条件 (1 つでも) |
|---|---|
| **買い替えを検討する** | SSD が異常 (`hw.ssd.*` が異常・予備領域の割れ・整合性エラー。内蔵 SSD は交換できない) / Apple のサポートの区分がオブソリート (純正の修理部品が無い) / 今の macOS がこの機種の最後のバージョンで、次のバージョンの対象から外れた (セキュリティ更新がいずれ止まる) / メモリの逼迫が注意以上で、スワップが多い状態が続いている (Apple Silicon は増設できない。1 回の診断では言わず、測り直しても同じときだけ) |
| **メンテナンスを勧める** | バッテリーが注意 (交換で済む。本体より安い。販売終了から最長 10 年まで交換を受け付ける) / SSD の摩耗が注意 / 熱による制限の記録がある (通気口の清掃) / 繰り返すパニック・クラッシュ / ゾンビ・残骸・長い起動時間 (再起動で消える) / ディスクの空きが注意以上 |
| **このまま使える** | 上のどれにも当たらない |

- **SSD の残りの目安**: 「摩耗」の % と「通電時間」から、1% あたりの通電時間 = 通電時間 ÷ 使用 % を出し、100% までの残りを今のペースで割る。
  使用 % は整数に丸められていて、値が小さいうち (10% 未満) は誤差が大きい。結論には「目安」と書き、書き込み総量 (TB) も添える
- **Apple の区分**: 販売終了から 5 年を超え 7 年以下がビンテージ (部品があれば修理できる)、7 年を超えるとオブソリート (修理を受けられない。
  ノートのバッテリーだけは最長 10 年)。区分は機種 ID で WebSearch して確かめ、引けなければ「未確認」と書く (推測で書かない)
- 判定不能の項目 (smartctl が無い等) が根拠に要るなら、結論を出す前に直し方 (`brew install smartmontools`) を示し、結論は「判定不能の項目を除いて」と断る

## tmux

- **サーバの常駐量はスクロールバックで決まる**: `history-limit` × pane の数が上限。`history-limit` を下げても既存の pane には反映されない。
  返すには clear-history (dotfiles では `prefix M-c` で全 pane。確認あり)
- **クライアントの数とカーネルのリーク**: macOS 15 / 26 では tmux のクライアントの数とカーネルの `data.kalloc.1024` の漏れが連動した
  (`docs/macos-health-check.md` の 2 節)。`proc.kalloc` が増えているなら、使っていない attach を閉じる
- **サーバが複数**: `-L` の隔離サーバやテストの残りのことがある。止める前に socket を確かめる (`tmux-probe-requires-socket-isolation.md`)。
  本番のサーバを止める操作はこの skill では行わない
- **終了したまま残った pane**: `remain-on-exit` の pane。要らなければその pane だけを閉じる

## nvim

- **画面と本体**: 0.10 以降は端末を持つ画面のプロセスと、端末を持たない `--embed` の本体に分かれる。本体だけが残っている (親も端末も無い) なら、
  閉じた端末の残りか、`--headless` で起こした道具・テストの残り。止める前に `args` で何者かを見る
- **言語サーバの重複**: 同じ言語サーバ (gopls など) が nvim の数より多く動いていたら、プロジェクトごとに起きているか、親を失ったものが混ざっている
- **古い swap**: 落ちたセッションの swap が残ると、そのファイルを開くたびに回復の確認 (E325) が出る。開いている nvim のものは動かさない
- **起動が遅い**: `nvim --startuptime <D>/startup.log +q` で時間のかかっているプラグインを見る

## Chrome

- **バージョンの食い違い**: 更新が入っても、再起動するまで古いバージョンが動く。古いバージョンの部品が消えて新しいタブが開けなくなることがある。`chrome://restart` でタブは戻る
- **ゾンビ**: Chrome の下にゾンビが溜まるのは長く起動したままのとき。再起動で消える
- **重いタブ**: Chrome のタスクマネージャ (メニュー > その他のツール > タスクマネージャ) でメモリ順に並べる。
  描画のプロセス (Renderer) が多いのは、タブ・拡張・広告の iframe ごとに 1 つ起きるため。使わないタブはメモリの節約 (設定 > パフォーマンス) に任せる
- **拡張**: 使っていない拡張は外す (常に 1 プロセスを持ち、全ページに読み込まれるものがある)
