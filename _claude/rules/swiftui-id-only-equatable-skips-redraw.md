# 等しさを id だけで定義した型を、SwiftUI の差分の入力に使うと、中身の更新が描き直されない (Swift)

> **トリガー型ルール。** `==` を id (や一部のフィールド) だけで比べる型を、View の引数・`ForEach` の要素・`@Observable` の値に流す瞬間、
> または、そうした型の値を同じ id のまま中身だけ置き換える経路 (重複の置き換え・上書き・編集) を足す瞬間に発動する。

## ルール

- **同じ id のまま中身を置き換える経路を作るなら、描き直されることを画面の測定 (frame・描いた文字列) で確かめるテストを先に書く**。
  SwiftUI は入力を `Equatable` の `==` で比べて同じとみなすと、`ForEach` の中身の生成も View の body も省く。モデルの値を読むテストは緑のまま通る
- 描き直させる手は 2 つで、どちらが要るかは測ってから決める (片方だけでは足りないことがある)
  - `ForEach` には等しさを持たない包み (`Identifiable` だけの struct) を渡す
  - View は id だけで等しくなる型を丸ごと持たず、表示に使う中身を値 (String など) で持つ
- **`==` を id だけにする理由 (アニメーションの粒度など) があるなら、その型を UI の差分の入力に使う所に、上の手当てとその理由を書く**
