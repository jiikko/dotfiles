# ブランチの切り替え・作成を無断で行わない

## ルール

- **`git switch` / `git checkout` / `git switch -c`（ブランチ作成含む）を、ユーザーの明示的な指示なしに実行しない**
- 「この作業は別ブランチでやるべき」と判断した場合でも、勝手に切り替えず**提案して確認を取る**（例: 「PR を分ける設計なので新ブランチを切りますか？ それとも現在のブランチで作業しますか？」）
- ユーザーが「〜のファイルを作って」「実装して」と言ったとき、それは**現在のブランチ上での作業指示**であり、ブランチ操作の許可を含まない
- 無断で切り替えてしまった場合は、即座に元のブランチへ戻し、作成したブランチが空なら削除して報告する
- ブランチが要ると思っても、ファイルの作成・編集は今のブランチのまま行う (untracked はブランチの切り替えに付いていくので、後で正しいブランチで拾える)

## 系: 自分が作っていない共有資源を扱う道具

- **他の session・プロセス・サーバなど、自分が作っていない共有資源を読む・操作する道具は、書く前に所有の範囲を決める**。
  既定は「自分が起こしたものだけ」。全部を見せて選べる形は、ユーザーの領分へ入力・停止できる経路を作る
