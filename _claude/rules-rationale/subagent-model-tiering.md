# サブエージェントは sonnet が使える箇所では sonnet を使い、アウトプットは必ず main agent が検閲する — なぜ・実例

ルール本文: `~/dotfiles/_claude/rules/subagent-model-tiering.md`（`~/.claude/rules/` に link され、毎セッション起動時に読まれる）。
この文書は起動時には読まれない。ルールの根拠・起源・実例を保存し、ルールを疑う・改訂する・却下するときに読む。

## なぜ

- main モデルを全サブタスクに使うとトークンコストと rate limit を無駄に消費する (session limit 到達で並行エージェントが途中死した実例: 2026-06-12)
- 一方で下位モデルは「もっともらしい誤り」の混入率が上がるため、コスト削減分は検閲で品質を担保する。分業: 下位モデルが作業し、main が判断する
