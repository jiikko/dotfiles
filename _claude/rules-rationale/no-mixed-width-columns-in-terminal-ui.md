# 端末 UI で全角と半角を同じ列に縦に並べない（桁が揃っても目には揃わない） — なぜ・実例

ルール本文: `~/dotfiles/_claude/rules/no-mixed-width-columns-in-terminal-ui.md`（`~/.claude/rules/` に link され、毎セッション起動時に読まれる）。
この文書は起動時には読まれない。ルールの根拠・起源・実例を保存し、ルールを疑う・改訂する・却下するときに読む。

## なぜ (起源: dotfiles statusline のカレンダー格子, 2026-08-23)

weekly ペース行を「色分割バー + カレンダー格子」に作り替えたとき、バーのセルを
**半角数字 + 空白** (`1 2 3 …`) にし、その下に**全角の曜日**を置いた。
カラム数は上下で一致しており、幅の計算上は完全に揃っていた。

それでも**半角数字が 2 カラム幅セルの左に寄る**ため、目にははっきりズレて見えた。
ユーザーから **2 回**指摘されている (1 回目は「日付なら 2 桁で埋まるから大丈夫」と
逃げ、2 回目でようやく全角数字へ変えて解決した)。

つまりこれは「幅の計算ミス」ではなく **「幅は正しいのに揃って見えない」** 種類の問題で、
幅を数えるテストでは検出できない。人が見るまで分からないので、**組む時点で混ぜない**
以外に防ぐ手立てがない。
