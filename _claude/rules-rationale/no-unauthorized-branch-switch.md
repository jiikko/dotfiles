# ブランチの切り替え・作成を無断で行わない — なぜ・実例

ルール本文: `~/dotfiles/_claude/rules/no-unauthorized-branch-switch.md`（`~/.claude/rules/` に link され、毎セッション起動時に読まれる）。
この文書は起動時には読まれない。ルールの根拠・起源・実例を保存し、ルールを疑う・改訂する・却下するときに読む。

## なぜ（起源: 2026-07-20）

複数PRに分割する設計に沿って「マイグレーションファイルを作成して」と指示された際、PR用ブランチが必要と判断して無断で `git switch -c` を実行した。ブランチはユーザーの作業状態そのものであり、勝手に変えると:

- working tree の内容が切り替わり、ユーザーが見ている画面・エディタの状態と食い違う
- 並行セッション・エディタの未保存変更・untracked ファイルが意図しないブランチに紐づく
- ユーザーのブランチ命名規則・PR運用の意図を先回りで壊す

「設計上ブランチを分けるべき」という正しさは、無断実行の理由にならない。コミット・push と同様、ブランチ操作もユーザーの領分。
